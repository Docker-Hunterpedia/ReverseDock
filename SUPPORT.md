# Getting help

| You want to… | Go to |
|---|---|
| Ask a question or share an idea | [GitHub Discussions](https://github.com/Docker-Hunterpedia/ReverseDock/discussions) (use the **Q&A** category for questions) |
| Report a bug or a Traefik/NGINX compatibility gap | [Open an issue](https://github.com/Docker-Hunterpedia/ReverseDock/issues/new/choose) and pick the matching form |
| Propose a design change | The **Design proposal** issue form; accepted proposals become ADRs in [`docs/decisions/`](docs/decisions/) |
| Report a security problem | [SECURITY.md](SECURITY.md); never a public issue |
| Read how it works | [`docs/`](docs/README.md): vision, architecture, roadmap |

ReverseDock is a free, volunteer-run project. There is no paid support and no enterprise edition; everyone gets the same help in public. Please search existing issues and discussions before posting, and include versions, deployment type and a minimal config.
