## 1. The twelve behaviours most likely to surprise a migrating user

1. **Priority is one number**: `priority` when set, else `len(rule)` in bytes of the rule *as written*. An explicit
   `priority: 1` sorts *below* every unprioritised rule (the usual Traefik idiom for catch-all routers). Ties go to
   `providers.precedence` (default: docker before file), then are unspecified.
2. **`PathPrefix` is a plain string prefix** (`/api` matches `/apiv2`), and **`HostRegexp`/`PathRegexp` are unanchored**.
3. **``Query(`k`)`` with one argument matches only an empty value** (`?k` or `?k=`), not "parameter present".
4. **Paths are normalised and sanitised before routing, and the backend receives that normalised path**; routing
   additionally decodes every percent-escape except RFC 3986 reserved characters and `%25`.
5. **`ClientIP`, `ipAllowList` and `rateLimit` use the TCP peer** (after PROXY protocol) unless an `ipStrategy`
   says otherwise; X-Forwarded-For is never used by `ClientIP`.
6. **Routers without `tls` only serve plain HTTP; routers without `entryPoints` attach to every entry point.**
7. **Redirect middlewares default to `permanent: false`**; codes are 302/307 or 301/308 depending on method (GET vs other).
8. **basicAuth accepts MD5-crypt (`$apr1$`, `$1$`), SHA1 (`{SHA}`) and bcrypt** — Traefik's own examples use `$apr1$`.
9. **forwardAuth**: GET to `address`, fixed 30 s timeout, transport error → **500**, any non-2xx → the auth server's
   status, headers and body go to the client; `authResponseHeaders` are always stripped from the client request first.
10. **rateLimit `burst` defaults to 1** and requests over the rate are *delayed* up to `1/(2·rate)` before 429.
11. **CORS preflights are answered by the headers middleware with 200 even for disallowed origins** (never reach the
    backend); `*` + credentials echoes the request `Origin`.
12. **Entry-point timeouts**: `readTimeout` 60 s bounds reading the *request* (uploads), `writeTimeout` 0, `idleTimeout`
    180 s; upstream `responseHeaderTimeout` is 0 (none) and dial is 30 s — Traefik has no upstream read/write timeout.

## 2. Routers

### 2.1 Priority and ordering
- Default priority = `len(rule)` (Go byte length of the raw rule string, whitespace and quotes included), applied
  when `priority == 0` — [src pkg/muxer/http/mux.go#L75](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L75),
  [src pkg/server/router/router.go#L246](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/router/router.go#L246).
  Doc example: ``HostRegexp(`[a-z]+\.traefik\.com`)`` = 34 beats ``Host(`foobar.traefik.com`)`` = 26
  ([doc reference/routing-configuration/http/routing/rules-and-priority](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#priority-calculation)).
- Explicit and computed priorities share one numeric space; `0` means "use length"; negative values are allowed
  (same doc page).
- Sort order: priority desc, then provider precedence desc
  ([src mux.go#L216](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L216)). Provider precedence is
  new in v3.7.0 ([cl v3.7.0 #12895](https://github.com/traefik/traefik/blob/v3.7.16/CHANGELOG.md?plain=1#L656)); default
  order, highest first: `kubernetesgateway, kubernetescrd, kubernetes, kubernetesingressnginx, swarm, docker, file,
  redis, knative, consul, consulcatalog, nomad, etcd, ecs, http, zookeeper, rest`; unlisted providers lose; it is
  only a tie-breaker for equal numeric priority
  ([doc reference/install-configuration/providers/overview](https://doc.traefik.io/traefik/reference/install-configuration/providers/overview/#providers-precedence)).
- No further tie-break (derived): routers are added while ranging over a Go map
  ([src router.go#L242](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/router/router.go#L242)) and re-sorted with
  the unstable `sort.Sort` ([src mux.go#L93](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L93)), so
  equal (priority, provider) routes have no defined order.
- User priorities above `MaxInt − 1000` are rejected
  ([src router.go#L30](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/router/router.go#L30),
  [#L250](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/router/router.go#L250)); the internal ACME HTTP-01
  router uses `MaxInt` ([src pkg/provider/traefik/internal.go#L130](https://github.com/traefik/traefik/blob/v3.7.16/pkg/provider/traefik/internal.go#L130))
  and entry-point redirects `MaxInt − 1`
  ([src pkg/config/static/entrypoints.go#L173](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/entrypoints.go#L173)).
- TLS and non-TLS routers are compiled into separate muxers and never compete
  ([src pkg/config/runtime/runtime_http.go#L22](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/runtime/runtime_http.go#L22)).
- No match → Go `http.NotFoundHandler` (404, body `404 page not found`)
  ([src mux.go#L40](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L40)).

### 2.2 Rule language and `ruleSyntax`
- Values in backticks or double-quoted **Go string literals** (all Go escapes); single quotes rejected; regexes use Go
  RE2 syntax; `&&`, `||`, `!`, parentheses with the usual precedence
  ([doc rules-and-priority](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#rules)).
- Matcher names are accepted in four spellings: as defined (`PathPrefix`), lower (`pathprefix`), UPPER (`PATHPREFIX`)
  and Title-of-lower (`Pathprefix`) ([src pkg/rules/parser.go#L31](https://github.com/traefik/traefik/blob/v3.7.16/pkg/rules/parser.go#L31)).
- Every matcher rejects empty arguments, e.g. ```Query(`q`, ``)``` is a config error
  ([src pkg/rules/parser.go#L124](https://github.com/traefik/traefik/blob/v3.7.16/pkg/rules/parser.go#L124),
  [src matcher_test.go#L854](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_test.go#L854)).
- Arity (v3): `Host`, `HostRegexp`, `Path`, `PathPrefix`, `PathRegexp`, `Method`, `ClientIP` = 1; `Header`,
  `HeaderRegexp` = 2; `Query` **and `QueryRegexp`** = 1 or 2
  ([src pkg/muxer/http/matcher.go#L16](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L16)).
- `ruleSyntax: v2|v3` per router, default from `core.defaultRuleSyntax` = `v3`
  ([src pkg/config/static/static_config.go#L125](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/static_config.go#L125));
  an unknown value falls back to v3 ([src pkg/muxer/http/parser.go#L63](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/parser.go#L63));
  both options are deprecated since v3.4 and will be removed in the next major
  ([mig v3.3→v3.4 "Rule Syntax Configuration"](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L1195),
  [doc rules-and-priority#rulesyntax](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#rulesyntax)).
  v2 matchers: `Host`, `HostHeader`, `HostRegexp` (`{name:re}`), `ClientIP`, `Path`, `PathPrefix`, `Method`, `Headers`,
  `HeadersRegexp`, `Query`, multi-valued ([src pkg/muxer/http/matcher_v2.go#L15](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_v2.go#L15)).

### 2.3 `Host`
Source: [src matcher.go#L71](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L71),
tests [matcher_test.go#L174](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_test.go#L174).
- Compared against the **canonical host**: `req.Host` with the port and IPv6 brackets removed, trimmed, lower-cased
  ([src pkg/middlewares/requestdecorator/request_decorator.go#L50](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/requestdecorator/request_decorator.go#L50),
  [src pkg/types/domains.go#L56](https://github.com/traefik/traefik/blob/v3.7.16/pkg/types/domains.go#L56)); the rule
  value is lower-cased and compared with `EqualFold` — case-insensitive, port-insensitive
  (`https://example.com:8080` matches ``Host(`example.com`)``).
- Trailing dot tolerated on either side (``Host(`example.com.`)`` ⇄ `example.com`)
  ([matcher_test.go#L214](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_test.go#L214)).
- `*.example.com` (v3.7.0+) matches exactly one label: `foo.example.com`, not `foo.bar.example.com`, not
  `example.com` ([mig v3.7.0](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L639),
  [src pkg/muxer/muxer.go#L23](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/muxer.go#L23)).
- Bare `*` matches every request, including requests without a host (v3.7.7+; before, it matched single-label hosts
  only) ([mig v3.7.7](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L453)).
- Non-ASCII values are config errors (use punycode); empty request host never matches (except `*`).
- IPv6 literals must be written **without** brackets (``Host(`::1`)``); a bracketed rule never matches because the
  canonical host has brackets stripped (derived,
  [request_decorator_test.go#L137](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/requestdecorator/request_decorator_test.go#L137)).
  A rule with a port (``Host(`a.com:8080`)``) is accepted but never matches (derived).
- Routing never looks at `X-Forwarded-Host` (derived: only the canonical `req.Host` and optional CNAME flattening).

### 2.4 `HostRegexp`
- Go regexp compiled as written and evaluated with `MatchString` — **not anchored**; matched against the lower-cased,
  port-stripped canonical host (and the CNAME-flattened host); non-ASCII patterns rejected
  ([src matcher.go#L124](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L124)). Upper-case literals
  therefore never match; docs use `^…$` and `(?i)` in examples
  ([doc rules-and-priority#host-and-hostregexp](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#host-and-hostregexp)).

### 2.5 `Path`, `PathPrefix`, `PathRegexp` and the routing path
- All three match the **routing path**: `URL.EscapedPath()` (after entry-point normalisation, §3.1) with every
  percent-escape decoded **except** RFC 3986 reserved characters `: / ? # [ ] @ ! $ & ' ( ) * + , ; =` and `%25`
  ([src mux.go#L102](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L102),
  [#L138](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/mux.go#L138)). So ``PathPrefix(`/foo bar`)`` matches
  `/foo%20bar`, while ``PathPrefix(`/foo/bar`)`` does not match `/foo%2Fbar`
  ([mig v3.4.1](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L1107)).
- `Path` = exact string equality (`/products` ≠ `/products/`); `PathPrefix` = `strings.HasPrefix`, **not
  segment-aware** (`/products` matches `/products-for-sale`); both values must start with `/`; `PathRegexp` is an
  unanchored regex and need not start with `/`
  ([src matcher.go#L144](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L144),
  [#L159](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L159),
  [#L175](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L175);
  [doc rules-and-priority#path-pathprefix-and-pathregexp](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#path-pathprefix-and-pathregexp)).

### 2.6 `Header`, `HeaderRegexp`
- Header name canonicalised (`http.CanonicalHeaderKey`, so names are case-insensitive); `Header` is an exact,
  case-sensitive comparison with **any one field value** of that header (field lines are not split on commas);
  `HeaderRegexp` is an unanchored regex against any value; docs recommend `(?i)` for case-insensitive values
  ([src matcher.go#L190](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L190),
  [#L200](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L200);
  [doc #header-and-headerregexp](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#header-and-headerregexp)).

### 2.7 `Query`, `QueryRegexp`
- Values come from Go `URL.Query()` (keys and values percent- and `+`-decoded, keys case-sensitive). Repeated keys:
  matches if **any** value matches (`?q=awesome&q=traefik` matches ``Query(`q`,`traefik`)``)
  ([src matcher.go#L215](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L215),
  [matcher_test.go#L854](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_test.go#L854)).
- One-argument ``Query(`mobile`)`` matches **only an empty value**: `?mobile` matches, `?mobile=true` does not
  ([matcher_test.go#L903](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher_test.go#L903),
  [doc #query-and-queryregexp](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#query-and-queryregexp));
  "any value" is spelled ``QueryRegexp(`mobile`, `^.*$`)``. One-argument `QueryRegexp` behaves like `Query`
  ([src matcher.go#L235](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L235)).
- By default `;` in the query is treated as `&` (§3.1), so `?a=1;b=2` has two parameters.

### 2.8 `Method`
- The rule value is upper-cased when the rule is built and compared case-sensitively with the request method, so
  ``Method(`get`)`` works ([src matcher.go#L61](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L61)).

### 2.9 `ClientIP`
- Uses `ip.RemoteAddrStrategy{}` = the TCP peer (`req.RemoteAddr`, replaced by the PROXY-protocol source when
  trusted); never X-Forwarded-For; IPv4, IPv6 or CIDR, one value per matcher
  ([src matcher.go#L40](https://github.com/traefik/traefik/blob/v3.7.16/pkg/muxer/http/matcher.go#L40);
  doc: "It only matches the request client IP and does not use the `X-Forwarded-For` header for matching" —
  [doc #clientip](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/#clientip)).

### 2.10 Entry points, TLS routers, defaults
- A router with a `tls` section handles only HTTPS requests; without it, only plain HTTP
  ([doc reference/routing-configuration/http/routing/router](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/router/),
  [src runtime_http.go#L22](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/runtime/runtime_http.go#L22)).
  A router `tls` section replaces (does not merge with) the entry point's `http.tls`
  ([doc reference/install-configuration/entrypoints](https://doc.traefik.io/traefik/reference/install-configuration/entrypoints/)).
- Routers without `entryPoints` attach to **all** entry points, or to those marked `asDefault: true` if any (router doc;
  [doc entrypoints#asdefault](https://doc.traefik.io/traefik/reference/install-configuration/entrypoints/#asdefault)).
- Entry-point `http.middlewares` are prepended to every router on that entry point (entry points doc).
- Router middlewares run in declared order ([doc router](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/router/)).
  Routers can form parent/child trees (`parentRefs`, multi-layer routing) since v3.6.0
  ([cl v3.6.0 #12130](https://github.com/traefik/traefik/blob/v3.7.16/CHANGELOG.md?plain=1#L1719)), and services can
  carry `middlewares` since v3.7.0 ([cl v3.7.0 #12544](https://github.com/traefik/traefik/blob/v3.7.16/CHANGELOG.md?plain=1#L673),
  [src http_config.go#L88](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/dynamic/http_config.go#L88)).

### 2.11 Regex flavour: Go RE2 vs Rust `regex`
- Go (`regexp/syntax`, read 2026-10-26, [pkg.go.dev/regexp/syntax](https://pkg.go.dev/regexp/syntax)): Perl classes are
  ASCII-only (`\d` = `[0-9]`, `\w` = `[0-9A-Za-z_]`, `\s` = `[\t\n\f\r ]`, `\b` ASCII); `\Q…\E` supported.
- Rust `regex` 1.13.1 ([docs.rs/regex](https://docs.rs/regex/latest/regex/), read 2026-10-26): `\d \w \s \b` are
  Unicode-aware unless `(?-u:…)`; no `\Q…\E`; character-class set operators `&&`, `--`, `~~` exist (Go treats `&` and
  `-` there literally). Both are unanchored searches with leftmost-first semantics, `(?i)` and `(?P<name>…)`.
- Effect: the same Traefik regex can match different inputs under rdock (``PathRegexp(`^/u/\d+$`)`` matches `/u/٣` in
  Rust only). Replacement strings are compatible: both expand `$1`, `${1}`, `$name`, and both read `$1x` as group `1x`
  ([doc middlewares/redirectregex](https://doc.traefik.io/traefik/reference/routing-configuration/http/middlewares/redirectregex/)).

## 3. Entry points (static configuration)

### 3.1 What happens to a request before routing
Handler chain built in [src pkg/server/server_entrypoint_tcp.go#L640–L731](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L662);
execution order (outermost first):
1. `populateRequestTLS`.
2. `denyOpaque`: a rootless target such as `http:example.com/admin` → **400**, not configurable (v3.7.13,
   [mig v3.7.13](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L125)).
3. `aliasHeadersStrategy` (`keep` default, with a startup warning; `delete`/`reject` act on header names containing
   any character other than letters, digits and `-`, reject = 400) (v3.7.12,
   [mig v3.7.12](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L159),
   [src #L704](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L704)).
4. `denyConnect`: `CONNECT` → **501** on every HTTP version (v3.7.15,
   [mig v3.7.15](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L12),
   [src #L884](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L884)).
5. `denyFragment`: `#` in the raw path → **400** ([src #L869](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L869)).
6. `normalizePath` (always on, v3.4.1+): decode percent-encoded *unreserved* characters, upper-case all other escapes;
   a truncated escape → 400 ([src #L1031](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L1031),
   [mig v3.4.1](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L1089)).
7. `sanitizePath` (`http.sanitizePath`, default **true**, v3.3.6+): RFC 3986 dot-segment removal and `//` collapse via
   `URL.JoinPath`, trailing slash kept (`/./foo/../bar//` → `/bar/`)
   ([src #L992](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L992),
   [src entrypoints.go#L114](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/entrypoints.go#L114),
   [doc entrypoints#sanitizepath](https://doc.traefik.io/traefik/reference/install-configuration/entrypoints/#sanitizepath),
   [mig v3.3.6](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L1208)).
8. Query semicolons: default `http.AllowQuerySemicolons` (`;` treated as `&`); `http.encodeQuerySemicolons: true`

### 3.3 Timeouts and life cycle
- `transport.respondingTimeouts`: `readTimeout` **60 s** ("maximum duration for reading the entire request,
  including the body"), `writeTimeout` **0** ("from the end of the request header read to the end of the response
  write"), `idleTimeout` **180 s**; 0 = no timeout
  ([src static_config.go#L45–L51](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/static_config.go#L45),
  [#L208](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/static_config.go#L208),
  [doc entrypoints](https://doc.traefik.io/traefik/reference/install-configuration/entrypoints/)). The 60 s read default dates
  from v2.11.2 / v3.0 ([cl v2.11.2 #10602](https://github.com/traefik/traefik/blob/v3.7.16/CHANGELOG.md?plain=1#L3277)).
- They are Go `http.Server` timeouts ([src #L779](https://github.com/traefik/traefik/blob/v3.7.16/pkg/server/server_entrypoint_tcp.go#L779)).
  Go 1.26 clears the read deadline once the request body is consumed
  ([go server.go#L697](https://github.com/golang/go/blob/release-branch.go1.26/src/net/http/server.go#L697)) and clears all
  deadlines on hijack ([#L325](https://github.com/golang/go/blob/release-branch.go1.26/src/net/http/server.go#L325)). So
  `readTimeout` cuts slow headers and slow uploads, but **not** long SSE responses (E1) or WebSockets; a non-zero
  `writeTimeout` would cut long responses.
- `transport.lifeCycle`: `graceTimeOut` **10 s** (active requests may finish; no new requests accepted),
  `requestAcceptGraceTimeout` **0** (keep accepting before shutdown so load balancers can deregister)
  ([src static_config.go#L233](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/static/static_config.go#L233), doc).
- `transport.keepAliveMaxRequests` / `keepAliveMaxTime` (0 = unlimited) then `Connection: close` or GOAWAY (doc).

## 5. Middlewares

### 5.0 Chain semantics (applies to every middleware below)
Middlewares wrap each other in declared order. Response changes are applied through a `ResponseModifier` when the
downstream handler writes its status, so a middleware's response phase also applies to responses **generated by later
middlewares** (401, 429, redirects), by `errors` pages and by the proxy itself (502/504); 1xx responses pass through
([src pkg/middlewares/response_modifier.go#L38](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/response_modifier.go#L38)).
A middleware that answers by itself (CORS preflight, redirect, 401) does not run its own response phase on that answer.

### 5.1 `headers` (custom and security headers)
- Composition: CORS + custom headers wrap the security handler, which wraps the next handler; a `headers` middleware
  with nothing configured is a config error
  ([src pkg/middlewares/headers/headers.go#L39](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/headers.go#L39)).
  Custom response headers are therefore applied after, and can override, security headers (derived).
- `customRequestHeaders`: value `""` deletes the header; `Host` sets the Host sent upstream (`req.Host`);
  `X-Forwarded-For: ""` sets the header to nil so the proxy does not append the peer; otherwise Set (replace)
  ([src header.go#L118](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L118),
  [#L131](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L131);
  [doc middlewares/headers](https://doc.traefik.io/traefik/reference/routing-configuration/http/middlewares/headers/)).
  There is no "append" operation.
- `customResponseHeaders`: `""` deletes, otherwise Set, overriding backend values
  ([src header.go#L71](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L71)).
- Security fields, implemented by `unrolled/secure` v1.0.9
  ([src secure.go#L19](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/secure.go#L19),
  [unrolled secure.go#L273](https://github.com/unrolled/secure/blob/v1.0.9/secure.go#L273)); all response values are Set:
  - `stsSeconds` (0/unset = no header), `stsIncludeSubdomains`, `stsPreload` →
    `Strict-Transport-Security: max-age=N[; includeSubDomains][; preload]`, **only when the request is HTTPS** (TLS,
    `https` URL scheme or an `sslProxyHeaders` match) or `forceSTSHeader`; never with `isDevelopment`
    ([secure.go#L368](https://github.com/unrolled/secure/blob/v1.0.9/secure.go#L368),
    [#L447](https://github.com/unrolled/secure/blob/v1.0.9/secure.go#L447)).
  - `frameDeny` → `X-Frame-Options: DENY`, overridden by `customFrameOptionsValue`; `contentTypeNosniff` →
    `X-Content-Type-Options: nosniff`; `browserXssFilter` → `X-XSS-Protection: 1; mode=block`, overridden by
    `customBrowserXSSValue`; `contentSecurityPolicy`, `contentSecurityPolicyReportOnly`, `referrerPolicy`,
    `permissionsPolicy` set verbatim; `publicKey` → `Public-Key-Pins` (HTTPS only).
  - `allowedHosts` (host taken from `hostsProxyHeaders` when present) → any other host gets **500 "Bad Host"**,
    except with `isDevelopment` ([secure.go#L38](https://github.com/unrolled/secure/blob/v1.0.9/secure.go#L38)).
- Removed in v3 (still parsed, no effect): `sslRedirect`, `sslTemporaryRedirect`, `sslHost`, `sslForceHost`,
  `featurePolicy` ([mig v2→v3 details](https://doc.traefik.io/traefik/migrate/v2-to-v3-details/),
  [src middlewares.go#L422](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/dynamic/middlewares.go#L422);
  `newSecure` does not pass them on).

### 5.2 CORS (fields of the `headers` middleware)
Fields: `accessControlAllowCredentials`, `accessControlAllowHeaders`, `accessControlAllowMethods`,
`accessControlAllowOriginList`, `accessControlAllowOriginListRegex`, `accessControlExposeHeaders`,
`accessControlMaxAge` (seconds), `addVaryHeader`; all empty/false by default
([src middlewares.go#L350](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/dynamic/middlewares.go#L350), headers doc).
- **Preflight** (`OPTIONS` + `Origin` + `Access-Control-Request-Method`) is answered directly: **200,
  `Content-Length: 0`, never forwarded** ("the middleware does not pass preflight requests to any service" — headers
  doc; [src header.go#L53](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L53),
  [#L143](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L143)). It carries
  `Access-Control-Allow-Credentials: true` (if set), `-Allow-Headers` (list; `*` with credentials echoes
  `Access-Control-Request-Headers`), `-Allow-Methods` (list; `*` with credentials echoes the requested method),
  `-Allow-Origin` only if the origin matched, `-Max-Age` only if configured (always `0` before v3.7.6), and
  `-Expose-Headers`. A disallowed origin still gets 200, just without `Access-Control-Allow-Origin`. No `Vary`.
- Origin matching: exact string per list item; `*` returns `*`, or echoes the request origin when credentials are on
  (v3.7.6); then the regex list (unanchored), echoing the origin
  ([src header.go#L197](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L197),
  [cl v3.7.6](https://github.com/traefik/traefik/blob/v3.7.16/CHANGELOG.md?plain=1#L416)).
- Normal responses: `Access-Control-Allow-Origin` Set when the origin matches (otherwise a backend value passes
  through untouched); `Allow-Credentials: true` whenever configured; `Expose-Headers` unless `*` with credentials;
  `Vary: Origin` appended (as `,Origin`) **only** with `addVaryHeader` ([header.go#L71](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/headers/header.go#L71)).

### 5.3 `redirectScheme` and `redirectRegex`
- Codes: `permanent: true` → **301 for GET, 308 for every other method (HEAD included)**; `false` → **302 / 307**;
  `Location` set, body = status text
  ([src pkg/middlewares/redirect/redirect.go#L92](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/redirect/redirect.go#L92)).
  `permanent` defaults to **false** for both middlewares; `scheme` is required; `port` is a string
  ([doc redirectscheme](https://doc.traefik.io/traefik/reference/routing-configuration/http/middlewares/redirectscheme/),
  [doc redirectregex](https://doc.traefik.io/traefik/reference/routing-configuration/http/middlewares/redirectregex/)).
- If the computed URL equals the current one, nothing is redirected and the request continues — `redirectScheme`
  on an HTTPS request is a no-op ([redirect.go#L73](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/redirect/redirect.go#L73)).
- `redirectScheme`: current scheme = `https` if TLS, then overridden by `X-Forwarded-Proto` (`http`/`ws` → http,
  `https`/`wss` → https); host and port from `Host`; target = `<scheme>://<host>[:port]<path?query>` where `port` is
  the configured one unless it is the scheme default — **the original port is dropped**
  ([src redirect_scheme.go#L27](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/redirect/redirect_scheme.go#L27),
  [#L59](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/redirect/redirect_scheme.go#L59)). Behind
  another proxy the last hop must be trusted (redirectScheme doc).
- `redirectRegex`: unanchored Go regex over `scheme://host[:port]` + raw `RequestURI` (path and query), scheme =
  `https` iff TLS (`X-Forwarded-Proto` is **not** consulted); replacement via Go `Expand` (`$1`, `${name}`; `$1x` =
  `${1x}`) ([src redirect_regex.go#L23](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/redirect/redirect_regex.go#L23)).

### 5.4 Path middlewares
- `stripPrefix` ([src strip_prefix.go#L56](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/stripprefix/strip_prefix.go#L56)):
  prefixes whitespace-trimmed; the first one that is a **string** prefix of the decoded path is removed (`/api`
  strips `/apiv2` to `/v2`); a leading `/` is ensured; the result is re-sanitised and **400 if sanitising changes it**
  (`/api./foo`, v3.7.3 / v3.6.19, [mig v3.7.3](https://github.com/traefik/traefik/blob/v3.7.16/docs/content/migrate/v3.md?plain=1#L541));
  `X-Forwarded-Prefix: <configured prefix>` is **added** (`Header.Add`, so stacked middlewares add values,
  [#L83](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/stripprefix/strip_prefix.go#L83)); query kept.
  `forceSlash` is deprecated and defaults to false ([#L37](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/stripprefix/strip_prefix.go#L37)).
- `stripPrefixRegex`: list of regexes; the first whose match is a prefix of the path is removed;
  `X-Forwarded-Prefix` = the matched text; same 400 rule
  ([src strip_prefix_regex.go#L49](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/stripprefixregex/strip_prefix_regex.go#L49)).
- `addPrefix`: non-empty `prefix` required, a leading `/` is ensured, no header
  ([src add_prefix.go#L45](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/addprefix/add_prefix.go#L45)).

### 5.8 `rateLimit`
- `average` (0 = no limit), `period` (1 s), `burst` (default **1**, minimum 1); rate = average / period

- Reject: **429**, `Retry-After: <ceil(delay) seconds>`, `X-Retry-In: <Go duration>`, body `Too Many Requests`
  ([rate_limiter.go#L181](https://github.com/traefik/traefik/blob/v3.7.16/pkg/middlewares/ratelimiter/rate_limiter.go#L181)).
- `sourceCriterion` (mutually exclusive): `ipStrategy` (default; with no fields = TCP peer), `requestHeaderName`

- Redis backend (`redis{endpoints, tls, username, password, db, poolSize, …, timeouts}`) since **v3.4.0**

## 6. Maintenance mode (Traefik has none)

### 6.1 What others do
- **Traefik v3.7.16**: no maintenance middleware (not in the `Middleware` struct,
  [src middlewares.go#L23](https://github.com/traefik/traefik/blob/v3.7.16/pkg/config/dynamic/middlewares.go#L23)). Users rely
  on plugins, e.g. [TRIMM/traefik-maintenance](https://github.com/TRIMM/traefik-maintenance) (`enabled`, flag file
  `triggerFilename`, page `filename`, `httpResponseCode` e.g. 503, `httpContentType`; no Retry-After or bypass
  documented) and [traefik-maintenance-warden](https://github.com/imKota/traefik-maintenance-warden)
  (`staticContent.path`, `dynamicContent.service`, `bypass.headers`, `bypass.paths`) — READMEs read 2026-10-26.
- **Caddy**: no directive; `error [<matcher>] <status>` raises an error rendered by `handle_errors`; a `file` matcher
  can test a flag file; `client_ip` (trusted-proxy aware) vs `remote_ip` (peer) matchers for bypass
  ([error](https://caddyserver.com/docs/caddyfile/directives/error), [matchers](https://caddyserver.com/docs/caddyfile/matchers),
  read 2026-10-26).
- **NGINX**: no directive; `return 503` + `error_page 503 /maintenance.html` (internal redirect, method becomes GET);
  `add_header` applies only to 2xx/3xx unless `always`, so `add_header Retry-After 600 always`; bypass via
  `geo`/`map` ([error_page](https://nginx.org/en/docs/http/ngx_http_core_module.html#error_page),
  [add_header](https://nginx.org/en/docs/http/ngx_http_headers_module.html#add_header), read 2026-10-26).
- **HAProxy 3.2**: `http-request return status 503 content-type text/html file /etc/haproxy/maint.html hdr Retry-After 600 if !{ src -f /etc/haproxy/allow.lst }`
  (status 200–599; `hdr` only for non-errorfile responses), or servers put in `maint` (`set server <b>/<s> state maint`),
  which leaves no server and yields 503 ([configuration.txt @v3.2.0 L15306](https://github.com/haproxy/haproxy/blob/v3.2.0/doc/configuration.txt#L15306),
  [management.txt L2498](https://github.com/haproxy/haproxy/blob/v3.2.0/doc/management.txt#L2498)).
- **Envoy**: route `direct_response` — "Return an arbitrary HTTP response directly, without proxying"
  ([route_components](https://www.envoyproxy.io/docs/envoy/latest/api-v3/config/route/v3/route_components.proto), 1.41.0-dev, read 2026-10-26).
- **Standards and guidance**: 503 is for "temporary overload or scheduled maintenance" and MAY carry `Retry-After`
  (HTTP-date or delay-seconds) ([RFC 9110 §15.6.4, §10.2.3](https://www.rfc-editor.org/rfc/rfc9110), June 2022). Google:
  use 503 + `Retry-After` for short pauses (a few days at most) and do not serve 503 for `robots.txt`, which blocks all
  crawling ([Search Central](https://developers.google.com/search/docs/crawling-indexing/pause-online-business), updated
  2025-12-10). gRPC clients map HTTP 503 (and 429/502/504) to `UNAVAILABLE` when no `grpc-status` is present
  ([grpc http-grpc-status-mapping.md](https://github.com/grpc/grpc/blob/master/doc/http-grpc-status-mapping.md), read 2026-10-26).

### 6.2 Proposed semantics for rdock `maintenance`
Current model: `{ enabled: true, status: 503, file?, retry_after?, allow: [] }`
(`crates/rdock-model/src/middleware.rs:287`). Proposal:
1. **Short-circuit** at its position in the chain with `status` (validator already restricts to 4xx/5xx; warn when not
   503). `rdock validate` warns when an auth middleware precedes it, so the page never requires a login.
2. **Body**: `file` read at apply time (size cap, e.g. 1 MiB; unreadable → config error, keep last-known-good),
   `Content-Type` from the extension (default `text/html; charset=utf-8`); without `file`, a built-in page (HTML when
   `Accept` contains `text/html`, else text). HEAD → headers only.
3. **Headers**: `Retry-After: <ceil(retry_after) s>` when set; always `Cache-Control: no-store`; no cookies. Outer
   middlewares' response phases still apply (security headers, CORS — §5.0).
4. **Bypass**: `allow` CIDRs against the *resolved* client IP (same source as `ip_allow`); bypassed requests continue
   unchanged. Add `bypass_paths` (prefixes such as `/healthz`, `/robots.txt`). No header/cookie secrets, because labels
   never carry secrets (architecture §4, rule 7); a secret bypass header could come later from the file provider via
   `${file:…}`.
5. **Upgrades and gRPC**: same status, no upgrade (gRPC clients see `UNAVAILABLE`).
6. **Toggle**: config change + hot reload (file watch, SIGHUP; later the `api` provider). Optional `trigger_file`
   (active while the file exists) observed by the config watcher, not stat'ed per request, so the data plane does no
   control-plane I/O. Optional `until` (RFC 3339): drives `Retry-After` and switches maintenance off automatically.
7. ACME HTTP-01 and rdock's own endpoints are answered before routing and are never affected.
8. With `errors`: maintenance answers are final when `file` is set; without `file`, an outer `errors` middleware
   matching the status may render the page (onion rule, §5.0).
9. Observability: access-log field `maintenance: served|bypassed`; counter `rdock_maintenance_responses_total{route}`.

## 7. `rdock-model` / `rdock-rules` vs Traefik v3.7.16 — mismatches and gaps
Severity: **High** = silent behaviour change or security exposure for a migrating user; **Med** = visible difference
or missing capability; **Low** = edge case. Paths are relative to the ReverseDock repository root.

### 7.1 Routing and the rule engine
- **R1 High — one-argument `Query`.** `crates/rdock-rules/src/ast.rs:49` documents `Query(key)` as "match presence
  only"; Traefik matches only an empty value (§2.7). Implement Traefik's meaning; "any value" is
  ``QueryRegexp(`k`, `^.*$`)``.
- **R2 High — one priority number.** Architecture §4 rule 4 ("priority desc → rule length desc → provider → name") and
  M-RT-02 ("explicit > rule length") must mean *effective* priority = explicit or `len(rule)`. If explicit priorities
  form a higher tier, the common Traefik idiom `priority: 1` on catch-all routers makes the catch-all win everything.
- **R3 Med — priority source.** Compute `len()` of the raw rule bytes as written (spaces and quotes count), not of the
  canonical `Display`; for structured matches use the canonical rendering and document it.
- **R4 Med — tie-break by provider.** rdock: `file > api > kubernetes > swarm > docker`, then name; Traefik (v3.7.0+):
  `kubernetesgateway > kubernetescrd > kubernetes > ingressnginx > swarm > docker > file > …`, then unspecified. Only
  equal numeric priorities are affected; keep rdock's deterministic name tie-break, document the reversed
  file/docker order (or expose a `precedence` list).
- **R5 High — matcher-name casing.** `crates/rdock-rules/src/parser.rs:267` matches names exactly; Traefik accepts
  `PathPrefix`, `pathprefix`, `PATHPREFIX`, `Pathprefix`. Accept the four spellings and canonicalise (lint warning).
- **R6 Med — lower-case `Method`.** `crates/rdock-rules/src/validate.rs:171` rejects ``Method(`get`)``; Traefik
  upper-cases it. Accept and normalise with a warning.
- **R7 Med — trailing dot.** `check_host` (`crates/rdock-rules/src/validate.rs:96`) rejects `example.com.` (empty
  label); Traefik accepts it and matches with or without the dot on either side.
- **R8 Med — IPv6 hosts.** rdock accepts only ``Host(`[::1]`)`` and rejects ``Host(`::1`)``; Traefik matches only the
  unbracketed form. Accept both, compare unbracketed.
- **R9 Low — `Host` with a port.** rdock errors; Traefik accepts a rule that can never match. Keep the error (it is a
  diagnostic, ADR-0003) and name the router in the migration report.
- **R10 Low — empty arguments.** Traefik rejects any empty argument; rdock accepts ```Header(`X`, ``)```,
  ```Query(`q`, ``)```, ```HostRegexp(``)``` (the last matches everything). Reject them.
- **R11 Low — `QueryRegexp` arity.** Traefik accepts one argument (= `Query`); `crates/rdock-rules/src/ast.rs:161`
  requires two.
- **R12 Low — string escapes.** Traefik takes full Go string literals (`\xhh`, `\uhhhh`, `\a`, octal, …); rdock's lexer
  accepts `\\ \" \n \r \t` only. Accept Go's set or report the escape precisely (it already does).
- **R13 High (security) — path sent upstream.** Architecture §7: "The *original* path is forwarded unless a rewrite
  applies." Traefik forwards the normalised and sanitised path (v3.3.6/v3.4.1, §3.1). Routing on one form and
  forwarding another invites router/backend disagreement (dot segments, case of escapes). Forward the normalised path
  by default, with an opt-out like `sanitizePath: false`.
- **R14 High — routing-path decoding.** Architecture §7 decodes unreserved escapes only; Traefik decodes every escape
  except reserved characters and `%25` before matching, so ``PathPrefix(`/foo bar`)`` and UTF-8 paths such as
  ``Path(`/café`)`` match encoded requests. Adopt Traefik's definition (keeping `%2F` encoded, as planned).
- **R15 Med — other path rules.** `//` collapse is "configurable" in rdock but part of default-on sanitising in
  Traefik (trailing slash kept); encoded-character rejection knobs are absent (Traefik default: allow all); `#` in the
  path → 400; query `;` is treated and forwarded as `&` by default.
- **R16 Med — `ClientIP` source.** rdock resolves the client IP from trusted proxies / `CF-Connecting-IP`
  (architecture §6); Traefik's `ClientIP` is the TCP peer. Same result without trusted proxies, different behind load
  balancers — document as an intended divergence (or offer a peer-based variant).
- **R17 Med — regex flavour.** Rust Perl classes are Unicode-aware, `\Q…\E` is missing, `&&`/`--` are class operators
  (§2.11). Rewrite `\d \w \s \b` to their ASCII forms (regex-syntax AST) or document and test with a corpus; run
  `HostRegexp` on the lower-cased, port-stripped host and lint upper-case literals.
- **R18 Med — TLS-routing model (for the v0.2 translator).** A Traefik router without `tls` serves plain HTTP only and,
  without `entryPoints`, sits on every entry point; rdock defaults are `defaults.listeners: [websecure]`, `tls: auto`,
  `redirect_http_to_https: true` (`crates/rdock-model/src/config.rs:80`). A migrated HTTP-only router silently becomes
  HTTPS with ACME and a redirect; `rdock migrate traefik` must say so or emit `listeners: [web]` + `tls: off`.
- **R19 Low — v2 syntax.** No `ruleSyntax` field: reject v2 rules with a v2-specific hint (the parser already hints at
  multi-argument matchers; add one for ``HostRegexp(`{name:re}…`)``, which Go compiles but never matches as meant).

### 7.2 Listeners (entry points)
- **L1 High — no client-side timeouts.** `Listener` (`crates/rdock-model/src/config.rs:101`) has no
  request-header/read/write/idle timeouts although B-NET-09 requires them. Add `listeners.*.timeouts` with Traefik's
  meaning and defaults (read = whole request 60 s, write 0, idle 180 s) and keep long SSE/WebSocket streams outside them.
- **L2 Med — no shutdown settings** (Traefik `graceTimeOut` 10 s, `requestAcceptGraceTimeout` 0); needed for B-NET-10.
- **L3 Med — forwarded headers.** Trust is global (`security.trusted_proxies`) instead of per entry point; no
  `insecure`, `connection`, `notAppendXForwardedFor`. Header set differs: Traefik never writes or strips `Forwarded`,
  always overwrites `X-Forwarded-Server`, sets `X-Real-Ip` to the peer (not the resolved client) and uses `ws`/`wss`
  in `X-Forwarded-Proto` for WebSockets. Document rdock's choices for B-NET-08.
- **L4 Med — HTTP→HTTPS redirect.** `defaults.redirect_http_to_https` covers "hosts that have a TLS route"; Traefik's
  entry-point redirect covers every host, defaults to 301/308 and targets the other entry point's port. Use 301 for
  GET and 308 otherwise; add a listener-level redirect for static-config migration.
- **L5 Med — header size.** `max_header_bytes` 32 KiB (`crates/rdock-model/src/settings.rs:51`) vs Traefik 1 MiB: headers
  between the two get 431 in rdock. Keep the safer limit, document it.
- **L6 Low — not modelled:** `http2.maxConcurrentStreams` (250), HPACK sizes, `keepAliveMaxRequests/Time`,
  `aliasHeadersStrategy` (rdock could default to `delete`, safer than Traefik's `keep`), entry-point default
  `middlewares` and default TLS.
- **L7 Med — PROXY protocol.** rdock: "Others are rejected" (`crates/rdock-model/src/config.rs:173`); Traefik accepts
  untrusted connections and ignores their header's address, makes the header optional for trusted sources, has an
  `insecure` mode and reads the header within `readTimeout`. Specify which rdock means (v0.6 anyway).
- **L8 Low — request hygiene parity** (B-SEC-08): `CONNECT` → 501, `#` in the path → 400, rootless targets → 400.

### 7.3 Services
- **S1 High — upstream timeouts.** `timeouts { connect 5 s, read 60 s, write 60 s, idle 90 s }`
  (`crates/rdock-model/src/service.rs:220`) vs Traefik `dialTimeout 30 s`, `responseHeaderTimeout 0`, `idleConnTimeout
  90 s` and no body read/write timeouts. Endpoints taking > 60 s to answer, SSE/long-poll/gRPC streams idle > 60 s and
  slow uploads that work under Traefik would fail. Split `response_header` from per-read `read`, and either default
  `read`/`write` off for streams or document loudly.
- **S2 Med — sticky defaults** (v0.4): rdock `secure` and `http_only` true, `SameSite=Lax`, `name` required
  (`service.rs:271`); Traefik false/false/unset, generated name, `path` `/`, optional `domain`.
- **S3 OK — `pass_host_header`** defaults to true in both.
- **S4 Med — upstream TLS gaps:** min/max version, cipher suites, several root CAs, `disableHTTP2`, `peerCertURI`,
  SPIFFE, pool size (`maxIdleConnsPerHost`; 200 in `default@internal`).
- **S5 Low — model shape:** per-server scheme and `preservePath`; strategies `hrw`, `leasttime`; weighted, mirroring
  and failover services; service-level middlewares (v3.7.0).
- **S6 Med — error statuses:** use 504 for timeouts, 502 for connect/reset/EOF, log 499 for client aborts, 503 for an
  empty pool — parity matters for `errors` ranges and dashboards.
- **S7 Low — health defaults** (v0.4) differ: Traefik 30 s / 5 s, GET, `followRedirects`, `path` required; rdock 10 s /
  2 s, `path` `/`, thresholds 2/3.
- **S8 Low — `responseForwarding.flushInterval`:** no rdock field; Pingora streams; the translator should drop it with
  an info diagnostic.

### 7.4 Middlewares
- **headers H1 High — security fields missing (B-SEC-05).** `set` covers constant headers but not HSTS-only-over-HTTPS,
  `forceSTSHeader`, `isDevelopment`, `allowedHosts` (500), `sslProxyHeaders`, `hostsProxyHeaders`. Add an `hsts` block
  (`max_age`, `include_subdomains`, `preload`, `force`; B-TLS-11) and translate the rest into `response.set`; reject
  `sslRedirect`, `sslTemporaryRedirect`, `sslHost`, `sslForceHost`, `featurePolicy` as "removed in Traefik v3".
- **H2 Med — empty values.** Traefik `""` deletes; an empty `set` value is undefined in rdock. Forbid empty `set`
  values (hint: `remove`); the translator maps `""` to `remove`.
- **H3 Med — special headers.** `request.set.Host` must change the upstream Host; `request.remove: [X-Forwarded-For]`
  must stop the later append.
- **H4 Med — response phase coverage.** Response phases must also run on locally generated answers (other
  middlewares' short-circuits, error pages, proxy errors), e.g. CORS headers on a 401 or 429 (§5.0).
- **cors C1 Med — `*` with credentials** is an error in rdock (`crates/rdock-model/src/validate.rs:861`) but valid in
  Traefik (echoes `Origin`). Keep the error; the migration diagnostic must explain it and suggest listing origins.
- **C2 Med — no origin regex** (`accessControlAllowOriginListRegex`).
- **C3 Med — origin syntax.** rdock accepts only `http(s)://host[:port]` (`validate.rs:844`), rejecting `null`,
  `capacitor://localhost`, `chrome-extension://…`, which Traefik compares as plain strings.
- **C4 Low —** default methods `GET, HEAD, POST` vs none (harmless); add `Vary: Origin` whenever the answer depends on
  `Origin` (safer than opt-in `addVaryHeader`); decide whether disallowed-origin preflights also get 200 (Traefik).
- **redirect D1 High — `permanent` default.** rdock `true` (`crates/rdock-model/src/middleware.rs:85`), Traefik `false`:
  `redirectscheme.scheme=https` yields 302/307 in Traefik and browser-cached 301/308 in rdock. Default to false, or make
  the translator always write `permanent`.
- **D2 Med — redirect details:** status by method (GET → 301/302, others incl. HEAD → 308/307); no-op when unchanged;
  `scheme` redirect honours `X-Forwarded-Proto` and drops the original port; regex redirect sees
  `scheme://host[:port]` + raw URI and ignores `X-Forwarded-Proto`.
- **path P1 Med — `strip_prefix_regex` missing** (the requested v0.1 set includes the regex variants; `rewrite`
  covers `replacePathRegex`).
- **P2 Med — path headers and rules:** `strip_prefix` adds `X-Forwarded-Prefix` (Add), is not segment-aware, ensures a
  leading `/`, returns 400 when sanitising changes the result; `rewrite` works on the escaped path, replaces every
  match and adds `X-Replaced-Path` only on a match; `replace_path` adds `X-Replaced-Path`.
- **P3 Low —** `add_prefix`/`replace_path` must start with `/` in rdock; Traefik prepends it (`api` works). Normalise with a warning.
- **basic_auth B1 High — hash formats.** rdock accepts `$argon2id$`, `$2a$`, `$2b$`, `$2y$`
  (`crates/rdock-model/src/validate.rs:66`); Traefik accepts MD5-crypt (`$apr1$`, `$1$`), `{SHA}` and bcrypt including
  `$2x$`, and its docs' examples are `$apr1$`. Most migrated user lists will fail. Decide under B-SEC-01: accept legacy
  formats read-only with a "weak hash" warning, or reject with a re-hash hint; at least add `$2x$`.
- **B2 Low —** `realm` has no default (Traefik `traefik`); no `headerField`; specify the failure response (401 +
  `WWW-Authenticate: Basic realm="…"`).
- **forward_auth F1 High (security) — `copy_headers`** must delete client-supplied values of those headers even when
  the auth server does not return them (Traefik does).
- **F2 Med — timeout:** default 5 s (`middleware.rs:165`, `:171`) vs Traefik's fixed 30 s; slow auth servers fail.
- **F3 Med — failure status:** "fail closed" has no status; Traefik answers 500 with an empty body (499 when the client
  cancelled). Pick 500 for parity or document 502/504.
- **F4 Med — missing fields:** `tls`, `authResponseHeadersRegex`, `addAuthCookiesToResponse`, `forwardBody` /
  `maxBodySize`, `maxResponseBodySize` (rdock should cap by default), `preserveLocationHeader`,
  `preserveRequestMethod`, `headerField`, `authSigninURL`.
- **F5 Low —** `trust_forward_header` (bool, default false) equals Traefik's explicit `false`; Traefik's unset legacy mode
  has no equivalent (it was inconsistent anyway).
- **ip I1 Med — IP source:** rdock uses the resolved client IP; Traefik the peer unless `ipStrategy` (`depth`,
  `excludedIPs`, `ipv6Subnet`). Document; the translator maps `ipStrategy` onto `security.trusted_proxies` or rejects it.
- **I2 Low —** no `rejectStatusCode` (403 default); accept `ipWhiteList` as an alias; `ip_deny` has no Traefik twin.
- **rate_limit Q1 High — `burst` default** = `average` (`middleware.rs:194`) vs Traefik 1.
- **Q2 Med — delay vs reject:** Traefik delays up to 1/(2·rate) before 429; send `Retry-After` (and optionally
  `X-Retry-In`) on 429.
- **Q3 Med — keys:** rdock `client_ip` (resolved), `route`, `header:<Name>` vs Traefik peer / `ipStrategy`,
  `requestHeaderName` (missing header = one shared bucket), `requestHost`; `average: 0` means off in Traefik but is an
  error in rdock.
- **compress Z1 Med — content types:** rdock compresses "common text types when empty" (`middleware.rs:241`); Traefik
  compresses everything except `application/grpc` and excluded types. No `excluded_content_types`, no
  `default_encoding`.
- **Z2 Med — algorithms:** default `[gzip]` vs `gzip, br, zstd`; the enum accepts `br`/`zstd`, which v0.1 cannot do.
- **Z3 Low — negotiation to copy:** HEAD, absent or empty `Accept-Encoding`, `q=0`, skip on `Content-Encoding` or
  `Content-Range`, `Vary` even when uncompressed, drop `Content-Length`/`Accept-Ranges`, never `application/grpc`;
  Traefik keeps `ETag` unchanged (weakening it would be a safe divergence).
- **errors E1 Med —** `path` corresponds to `query`; missing `{originalStatus}`, `{url}`, `status_rewrites`,
  `error_request_headers`.
- **E2 Low —** rdock validates codes (100–599, low ≤ high), Traefik does not; the translator must split
  comma-separated label values.
- **E3 Low —** specify the page request as Traefik does (GET, original Host and headers, error service's headers and
  body, original or rewritten status) and that it also catches proxy errors and later middlewares' answers.
- **G1 High — unknown keys are warnings** unless `--strict` (`crates/rdock-config/src/lib.rs:183`): a Traefik-style or
  misspelt key inside a middleware (`stsSeconds`, `ipStrategy`, `authResponseHeadersRegex`) is ignored. Make unknown
  keys inside `middlewares.*`, structured `match` and `services.*.tls` errors even without `--strict`.
- **G2 Med — no `chain` middleware,** common in label setups; add it or flatten chains in the translator.

### 7.5 What v0.1 must reject as "not supported yet" (instead of ignoring)
v0.1 scope per `docs/07-roadmap.md`: B-NET-01…13, B-TLS-01/09/10/11, B-CFG-01…10, B-SEC-01…09/11/12, B-OBS-01…03 and
the middleware list above. The model already contains:

| Field | Planned in |
|---|---|
| `acme`; route `tls.dns_provider`, `tls.domains`, `tls.auto` needing issuance; **`defaults.tls: auto` (the default)** | v0.3 (B-TLS-02…08). In v0.1 `auto` must resolve to a matching manual certificate (B-TLS-09/10) or fail with a diagnostic, never fall back silently to the default certificate |
| `listeners.*.proxy_protocol` | v0.6 (M-L4-03) |
| `listeners.*.protocol: tcp/udp`, `tcp_routes`, `tcp_services` | v0.6 (M-L4-01/02); UDP v0.8 (M-L4-04) |
| `services.*.split` | v0.4 (M-RT-03) |
| `load_balancer.policy` other than `round_robin`, `hash_on` | v0.4 (M-LB-01/02) |
| `services.*.health` (active, passive) | v0.4 (M-LB-04/05) |
| `services.*.retries` | v0.4 (M-LB-06, ADR-0010) |
| `services.*.sticky` | v0.4 (M-LB-03) |
| `services.*.tls.cert_file/key_file` (upstream mTLS) | v0.4 (M-TLS-01); `verify`, `server_name`, `ca_file` are v0.1 (B-NET-02) |
| `compress.algorithms: br/zstd` | v0.4 (M-TM-06) |
| `rate_limit.key: route / header:*` | v0.4 (M-TM-01) unless implemented now (B-SEC-03 is per-IP) |
| `providers.docker/swarm/kubernetes` | v0.2 / v0.6 / v0.7 |
| `trusted_proxies: cloudflare`, `client_ip_header: cf-connecting-ip` (and `auto`'s CF branch) | v0.3 (W-CF-01/02); `auto` degrades to X-Forwarded-For with an info diagnostic |
| `observability.tracing` | v0.4 (M-OBS-01) |
| `admin.dashboard: true` (default) | v0.5 (M-ADM-03, F-UI) — report it as unavailable |

`examples/config/rdock.full.yaml` is validated in strict mode by CI and uses many of these (ACME, DNS provider,
`least_conn`, health, retries, Cloudflare, Docker, tracing). Add an "unsupported in this version" diagnostic that is
fatal for `rdock run`/apply and reported by `rdock validate` with the target milestone (or a `--target` flag), so the
example can stay the target-state document.

### 7.6 Decisions worth an ADR before implementing v0.1
1. Path normalisation and the path sent upstream (R13, R14, R15) — security model.
2. Client-IP source for `ClientIP`, `ip_allow`, `rate_limit` and `maintenance.allow` (R16, I1, Q3).
3. Redirect `permanent` default and HTTP→HTTPS status codes (D1, L4).
4. Legacy basic-auth hashes (B1).
5. Listener and upstream timeout model and defaults (L1, S1).
6. Unknown-key severity inside security-relevant objects (G1).
7. Maintenance semantics (§6.2).
