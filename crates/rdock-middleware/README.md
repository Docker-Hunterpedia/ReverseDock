# rdock-middleware

Built-in middlewares: headers, redirects, rewrites, basic and forward auth, IP filters, rate limits, CORS, compression, error pages, maintenance mode and static files.

**v0.1:** the P0 set — `headers` (with HSTS), `redirect`, `rewrite`, `strip_prefix`, `add_prefix`, `replace_path`, `basic_auth` (argon2id, bcrypt; legacy Apache MD5 and SHA-1 with a warning), `forward_auth`, `ip_allow`, `ip_deny`, `rate_limit`, `cors`, `compress` (streaming gzip), `errors` and `maintenance`. Each implements the `Middleware` trait (`request`, `response`, `error_page`); `build` creates them from the `rdock-model` types. Brotli and zstd follow later. Design: [architecture §8](../../docs/05-architecture.md).

**v0.6:** `static` (F-WEB-01) serves files from a directory opened once with cap-std: strong `ETag`s, RFC 9110 conditionals and ranges, precompressed sidecars and an SPA fallback. A `Reply` body is in memory (`Body::Bytes`) or ranges of an open file (`Body::File`) that the proxy reads chunk by chunk.

**v0.8:** the phased pipeline (F-EXT-01, ADR-0030). `Middleware` gains `capabilities` (declared phases, a typed per-request state slot, a body hold), `upstream_request`, `request_body`, `response_body` and `log`; `Chain` computes per-route flags once and runs each phase in its order (list order in, reverse order out). `held` is the shared request-body holder (memory to 64 KiB, then an unlinked `0600` spool file); `hold_body` is its first user.

**v0.8 (extensions):** `plugin` wraps a native plugin (`rdock-plugin-api`) as a middleware: owned `http`-typed heads written back when changed, the plugin's declared capabilities, typed state in its slot, and panic isolation (`rdock_plugin_panics_total{plugin}`, `500` for that request). `agent` asks an out-of-process service (`protocol: rdock` JSON verdicts or `protocol: forward` replays) with the body held up to `max_body`, `on_error` (default `deny`), a circuit breaker and header allow-lists. `Context` tells middlewares whether the request has a body (`has_body`) and lets one waive its body hold for a request (`waive_body_hold`). `client` gains `ClientTls` (CA bundle, server name, client certificate) for agents over TLS.
