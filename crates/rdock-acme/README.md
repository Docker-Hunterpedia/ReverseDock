# rdock-acme

Automatic certificates ([ADR-0020](../../docs/decisions/0020-automatic-https.md)): the certificate manager, a background task that keeps one certificate per requested set of names, orders them with [instant-acme](https://crates.io/crates/instant-acme) (ring), answers HTTP-01 and TLS-ALPN-01 challenges through `rdock_tls::Challenges`, stores accounts and certificates under `$RDOCK_DATA_DIR/acme` (0600, atomic writes, a lock against a second process) and publishes issued certificates to the data plane's resolver. The data plane only reads; ACME or CA outages never stop traffic that already has certificates.

**Status:** HTTP-01, TLS-ALPN-01 and DNS-01 issuance (the `DnsSolver` trait with `exec` and `webhook` providers; Cloudflare lives in `rdock-cloudflare`, Route 53, Google Cloud DNS, Azure DNS, DigitalOcean, Hetzner, deSEC and RFC 2136 in `rdock-dns-providers` since v0.6), ARI renewal with a fallback at a third of the lifetime, staging rehearsal after failures, status, metrics and alert webhooks (v0.3). The local CA (`local_ca`, `LocalIssuer`) certifies `localhost`, reserved private suffixes and private addresses from a name-constrained root in `$RDOCK_DATA_DIR/pki` (v0.3, B-TLS-13). End-to-end test against Pebble: `crates/rdock/tests/e2e_acme.rs` (`RDOCK_ACME_TESTS=1`, needs Docker).

**v0.9 (released in 0.9.0-alpha.1, [ADR-0031](../../docs/decisions/0031-v0-9-scale.md)):** with a `ClusterStore` (`cluster.rs`, `rdock-cluster`) each name is ordered under a lease with a fencing token, the store is re-checked after taking it, the order and its new key are journalled so the next holder resumes it, and the account and the renewal time are shared; HTTP-01 and TLS-ALPN-01 answers are copied to every live member before the CA validates. A certificate is written to `certs/<name>/next/` and `meta.json` (naming the chain's SHA-256) is replaced with compare-and-swap before `cert.pem` and `key.pem` are; a directory written by 0.8 loads unchanged. Without a cluster the behaviour is a single instance's, with the same storage layout.
