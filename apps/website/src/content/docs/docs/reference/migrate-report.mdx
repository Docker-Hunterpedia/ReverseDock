<Status maturity="beta" /> `rdock migrate traefik` accounts for **every source item** (a label, a key of a configuration file, a flag, an environment variable) **exactly once**, at one of four levels. Each finding has a stable code, the source location, the generated object's path in rdock.yaml when there is one, a message and a hint. A test fails when an item has no finding or two. Findings about the written result as a whole (a validation error of a fragment, labels left to the Docker provider) have no source item and are counted apart.

| Level | Meaning | In the output |
|---|---|---|
| `exact` | The same behaviour | written |
| `approximate` | Works, with a stated difference | written; listed at the top of the output |
| `manual` | Needs a decision | left out, or the route is written `enabled: false` so it never goes live without (say) its authentication; the finding says what to do |
| `dropped` | No equivalent | left out; the finding says why |

Output:

- **Text** on standard error: the counts first, then the findings grouped by level (manual, dropped, approximate). The YAML on standard output starts with the same counts and every finding that is not exact as comments.
- **`--report FILE`**: the report as JSON, described by [`schema/migrate-report.v1.json`](https://github.com/Docker-Hunterpedia/ReverseDock/blob/main/schema/migrate-report.v1.json) (`rdock schema --migrate-report` prints it). `--report -` writes it to standard error instead of the text.
- **`--strict`**: exit `2` when any finding is `manual` or `dropped`.

Exit codes: `0` migrated (findings may exist), `1` the input is not a Compose file or a Traefik configuration, `2` an error (an unreadable file) or, with `--strict`, something to review. The same codes as `rdock migrate config` (where `2` is an I/O error).

The JSON format and the codes are beta: fields and codes may be added in a minor release, and a change to an existing one comes with a migration note.

## Finding codes

| Code | Level | Meaning | What to do |
|---|---|---|---|
| `compose.deploy_labels` | approximate | `deploy.labels` (Swarm) were read as container labels. | To keep them on the stack, run ReverseDock with `providers.swarm` instead of migrating them. |
| `compose.interpolation.invalid` | manual | A `${…}` reference that Compose cannot read. | Fix the reference; `$$` writes a literal `$`. |
| `compose.interpolation.required` | manual | A `${NAME?message}` reference whose variable is not set: Compose would refuse the file. | Pass the variable with `--env-file` (or `--process-env`). |
| `compose.interpolation.unset` | manual | A `${NAME}` reference whose variable is not set: Compose would use an empty string. | Pass the variables with `--env-file FILE` (Compose's `.env`), or `--process-env` to read this process's environment. |
| `compose.service` | exact | A Compose service with Traefik or ReverseDock labels, reachable by its service name. | None. |
| `compose.service.not_exposed` | manual | A service with Traefik router labels and no `traefik.enable`: Traefik routes it (its `exposedByDefault` is `true`), ReverseDock does not. | Add `traefik.enable=true`, rerun with `--expose-by-default`, or migrate the static configuration (`--static`), which writes Traefik's setting explicitly. |
| `compose.service.port_assumed` | approximate | No `expose`, `ports` or port label: port 80 was assumed. | Traefik uses the port the image exposes, which a Compose file does not say: check it, or add `traefik.http.services.<name>.loadbalancer.server.port`. |
| `compose.service.problem` | manual | A problem with a service as a whole (the message says which: several exposed ports, a network…). | Fix what the message names. |
| `compose.service.traefik` | exact | The service that runs Traefik itself: its labels and static flags are read, the service is not routed. | Replace its image with ReverseDock's and remove Traefik's flags (`rdock run` does not accept them). |
| `output.invalid` | manual | The written configuration has a validation error on its own (for example a reference to an object in another file). | Check it with `rdock validate` once the rest of the configuration is in place. |
| `output.labels_live` | exact | With `--full` and a Compose file, the label routes are not written: the Docker provider reads the same labels at run time. | Keep the labels on the containers. |
| `rdock.label` | exact | An `rdock.*` label, read as it is. | None. |
| `rdock.label.invalid` | manual | An `rdock.*` label that was refused. | Fix it as the message says. |
| `traefik.file.approximate` | approximate | A key of a dynamic configuration file written with a stated difference. | Read the difference. |
| `traefik.file.exact` | exact | A key of a dynamic configuration file translated with the same behaviour. | None. |
| `traefik.file.manual` | manual | A key of a dynamic configuration file that needs a decision (the message says which). | Write the setting in rdock.yaml. |
| `traefik.file.toml` | manual | A TOML file: only YAML is read. | Convert the file to YAML (the keys are the same), then run the migration again. |
| `traefik.file.unsupported` | dropped | A key of a dynamic configuration file without an equivalent. | None, or the alternative the message names. |
| `traefik.file.users_file` | exact | `basicAuth.usersFile`: the same file is named, never read or copied. | Make the file readable by ReverseDock at the same path. |
| `traefik.label.approximate` | approximate | A Traefik label translated with a stated difference (the coverage table's note). | Read the difference; the supported Traefik subset page lists them all. |
| `traefik.label.exact` | exact | A Traefik label translated with the same behaviour. | None. |
| `traefik.label.inactive` | exact | A label of a container that `traefik.enable=false` turns off: Traefik ignores it too. | None. |
| `traefik.label.invalid` | manual | A supported Traefik label whose value was refused. | Fix the value as the message says. |
| `traefik.label.manual` | manual | A Traefik label that needs a setting outside labels (the message says which). | Write the setting in rdock.yaml. |
| `traefik.label.not_exposed` | manual | A label of a container nothing exposes (no `traefik.enable`): it was not migrated. | See `compose.service.not_exposed`. |
| `traefik.label.object_ignored` | manual | A label of an object that was left out (the message says why: no port, an ambiguous service, a conflict…). | Fix what the message names; the object's other labels are then translated. |
| `traefik.label.unknown` | dropped | A `traefik.*` label that is not a Traefik v3.7 label. | Check its spelling against Traefik's reference. |
| `traefik.label.unsupported` | dropped | A Traefik label without an equivalent (the message says why). | None, or the alternative the message names. |
| `traefik.route.disabled` | manual | A route written disabled (`enabled: false`) because a middleware or service it uses was not migrated, so it never goes live without, say, its authentication. | Replace what was not migrated, then remove `enabled: false`. |
| `traefik.router.all_entrypoints` | approximate | A router without `entrypoints`: Traefik attaches it to every entry point, ReverseDock to `defaults.listeners`. | Name the entry points, or set `defaults.listeners`. |
| `traefik.router.plain_http` | approximate | A router without `tls`: Traefik serves it as plain HTTP (unless its entry point sets `http.tls`); the migrated route gets HTTPS with an automatic certificate and HTTP is redirected. | Keep the HTTPS default (recommended), or write `tls: off` on the route; with `--static`, the entry points decide and the route is written as Traefik serves it. |
| `traefik.static.approximate` | approximate | A static setting written with a stated difference. | Read the difference. |
| `traefik.static.credentials` | manual | A credential (DNS provider, EAB key, provider password): never copied; the output refers to an environment variable. | Set the variables the message names in ReverseDock's environment (or use `${file:…}` references). |
| `traefik.static.exact` | exact | A static setting translated with the same behaviour. | None. |
| `traefik.static.expose_by_default` | exact | Traefik's `exposedByDefault` (default `true`) written explicitly as `expose_by_default`. | This is a security choice: every container with labels is routed. Set it to `false` and add `traefik.enable=true` where wanted, which is ReverseDock's default. |
| `traefik.static.manual` | manual | A static setting that needs a decision (the message says which). | Write the setting in rdock.yaml. |
| `traefik.static.unknown` | dropped | A key that is not a Traefik v3.7 static option this tool knows. | Check its spelling against Traefik's reference. |
| `traefik.static.unsupported` | dropped | A static setting without an equivalent (the message says why). | None, or the alternative the message names. |
