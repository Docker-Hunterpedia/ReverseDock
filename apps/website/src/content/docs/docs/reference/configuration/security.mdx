Client IP trust and request limits.

## `security.client_ip_header`

**Type:** `auto` · `x-forwarded-for` · `x-real-ip` · `cf-connecting-ip` · **Default:** `auto`

Where the real client IP comes from.

- `auto`: `CF-Connecting-IP` when the peer is in Cloudflare's ranges, otherwise the right-most untrusted `X-Forwarded-For` entry.
- `x-forwarded-for`: Right-most untrusted `X-Forwarded-For` entry.
- `x-real-ip`: `X-Real-IP` from a trusted proxy.
- `cf-connecting-ip`: `CF-Connecting-IP` from a trusted proxy (Cloudflare's edge or a listed network); needs `cloudflare` in `trusted_proxies`.

## `security.limits`

**Type:** object · **Default:** see the fields below

Request size limits.

### `security.limits.max_body_bytes`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize)

Request body size, also enforced for chunked bodies. Unlimited when omitted.

### `security.limits.max_header_bytes`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `64KiB`

Total size of the request line and headers.

### `security.limits.max_headers`

**Type:** `integer` · **Default:** `100`

Number of request headers.

### `security.limits.max_in_flight`

**Type:** `integer`

Requests in flight across every listener; more are answered `503` with `Retry-After` (load shedding). Unlimited when omitted.

### `security.limits.max_uri_bytes`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `8KiB`

Request target (path and query) length.

### `security.limits.upstream_idle_connections`

**Type:** `integer` · **Default:** `4096`

Idle keep-alive connections to backends kept per listener for reuse. Connections beyond it are closed when their request ends, so a busy listener keeps opening new ones. Applies to listeners started after the change.

## `security.trusted_proxies`

**Type:** list of [`TrustedProxy`](/docs/reference/configuration/#trustedproxy)

Proxies whose forwarded headers are believed. Headers from anyone else are replaced.
