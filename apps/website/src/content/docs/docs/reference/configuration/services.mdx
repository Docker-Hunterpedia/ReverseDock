## `services.<name>.load_balancer`

**Type:** object · **Default:** `{"hash_on":null,"policy":"round_robin"}`

How a backend is chosen for each request.

### `services.<name>.load_balancer.hash_on`

**Type:** `string`

Header or cookie name for `header_hash` and `cookie_hash`.

### `services.<name>.load_balancer.policy`

**Type:** `round_robin` · `random` · `least_conn` · `least_requests` · `p2c` · `ip_hash` · `header_hash` · `cookie_hash` · **Default:** `round_robin`

Selection policy.

- `round_robin`: Weighted round-robin.
- `random`: Weighted random.
- `least_conn`: Fewest open connections.
- `least_requests`: Fewest in-flight requests.
- `p2c`: Power of two random choices.
- `ip_hash`: Consistent hash of the client IP.
- `header_hash`: Consistent hash of a request header (`hash_on`).
- `cookie_hash`: Consistent hash of a cookie (`hash_on`).

:::note[Planned for v0.4]
Policies other than `round_robin` and `random`: accepted by `rdock validate` with a warning, refused by `rdock run` until v0.4.
:::

## `services.<name>.scheme`

**Type:** `http` · `https` · `h2c` · **Default:** `http`

Protocol spoken to the backends. gRPC uses `h2c` (cleartext) or `https`.

- `http`: HTTP/1.1 in cleartext.
- `https`: HTTP/1.1 or HTTP/2 over TLS.
- `h2c`: HTTP/2 in cleartext (gRPC without TLS).
