The control plane's own settings, read only by `rdock control run`.

## `control.history`

**Type:** `integer` · **Default:** `50`

Published revisions kept for listing and rollback. Default 50 (1–1000).

## `control.identity_lifetime`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30d`

Lifetime of the client certificate each data plane receives; it is renewed when a third is left. A data plane whose certificate expires while the control plane is away keeps serving but must enrol again with a new token. Default 30d (1h–90d).

## `control.join_token_ttl`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1h`

How long a join token from `rdock control token create` stays usable. Default 1h (1m–30d).

## `control.listener`

**Type:** [`ListenAddress`](/docs/reference/configuration/#listenaddress) · **Default:** `127.0.0.1:7443`

The cluster listener data planes connect to (mutual TLS, HTTP/2). Default `127.0.0.1:7443`: set an address other machines reach.

## `control.name`

**Type:** `string`

A display name for the cluster.

## `control.names`

**Type:** list of `string`

DNS names and IP addresses on the control plane's server certificate, as data planes write them in `cluster.control.url`. `localhost`, `127.0.0.1`, `::1` and the listener's IP are always included.

## `control.offline_after`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m30s`

A data plane that has not asked for a bundle for this long is shown as away and is not waited for by challenge barriers. Default 90s (10s–1h).
