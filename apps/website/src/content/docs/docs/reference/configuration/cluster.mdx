Membership of a cluster (H-HA-01…03): the control plane this data plane takes its configuration from, and where certificates are shared.

<Status maturity="beta" />

## `cluster.control`

**Type:** object

The control plane this data plane takes its configuration from.

### `cluster.control.ca_file`

**Type:** `string`

The cluster CA certificate (PEM), as `rdock control ca` prints it. One of `ca_file` and `ca_pin` is required.

### `cluster.control.ca_pin`

**Type:** `string`

The SHA-256 of the cluster CA certificate (DER), as `sha256:<64 hex digits>`; `rdock control token create` prints it. The first connection accepts the control plane only when its chain contains a CA with this digest; the CA is then kept in `identity_dir`.

### `cluster.control.identity_dir`

**Type:** `string`

Where the instance's key, certificate and the cluster CA are kept (mode 0700). Default `$RDOCK_DATA_DIR/cluster`.

### `cluster.control.join_token`

**Type:** `string`

The single-use join token from `rdock control token create`, used only while the instance has no identity yet. A secret: reference a file, e.g. `"${file:/run/secrets/rdock-join}"`.

### `cluster.control.poll_timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30s`

How long one request for the next bundle waits on the control plane before it is asked again. Default 30s (5s–5m).

### `cluster.control.url`

**Type:** [`HttpUrl`](/docs/reference/configuration/#httpurl) · **Required**

The control plane's cluster address, e.g. `https://control.example.com:7443`. Always `https`.

## `cluster.instance`

**Type:** `string`

This instance's name in leases and the control plane's instance list: letters, digits, `.`, `-` and `_`, at most 63 characters. Default: the identity the control plane gave at enrolment, or (without a control plane) an id generated once and kept in `$RDOCK_DATA_DIR/cluster/instance`.

## `cluster.limits` <Status maturity="beta" />

**Type:** object

How `rate_limit` and `quota` with `scope: cluster` share their budgets.

### `cluster.limits.fallback`

**Type:** `share` · `instance` · **Default:** `share`

`share` (default) or `instance`: what an instance enforces while the store is away.

- `share`: Its share: the limit divided by the number of instances it last knew of, against what it admitted itself in the window. The cluster stays near the limit under even load.
- `instance`: The whole limit on its own, as with `scope: instance` (N instances admit up to N times the limit).

### `cluster.limits.headroom_percent`

**Type:** `integer` · **Default:** `10`

How far an instance may admit beyond the budget it has claimed, as a percentage of the limit split between the instances: larger values absorb store latency at high request rates, smaller ones tighten the bound. Default 10 (0–100).

### `cluster.limits.redis`

**Type:** object

The Redis-compatible server, for `store: redis`.

#### `cluster.limits.redis.allow_plaintext`

**Type:** `boolean` · **Default:** `false`

Allow `redis://` (no TLS) to an address that is not a loopback address. Off by default: the password and the counters would cross the network in clear.

#### `cluster.limits.redis.ca_file`

**Type:** `string`

CA certificates (PEM) to verify the server with instead of the system's roots.

#### `cluster.limits.redis.key_prefix`

**Type:** `string` · **Default:** `rdock:`

Prefix of every key rdock writes. Default `rdock:`.

#### `cluster.limits.redis.password`

**Type:** `string`

The password. A secret: reference a file or a variable, e.g. `"${file:/run/secrets/redis}"`.

#### `cluster.limits.redis.timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1s`

The longest a connection or a command may take before the store counts as away. Default 1s (100ms–10s).

#### `cluster.limits.redis.url`

**Type:** `string` · **Required**

`rediss://host:6379/0` (TLS) or `redis://host:6379/0`; the path is the database number. Plain `redis://` is accepted for loopback addresses only, unless `allow_plaintext` is set. Credentials belong in `username` and `password`, not here.

#### `cluster.limits.redis.username`

**Type:** `string`

The ACL user name (Redis 6 and later); without it `AUTH` sends only the password.

### `cluster.limits.store`

**Type:** `cluster` · `redis` · **Default:** `cluster`

`cluster` (default) or `redis`.

- `cluster`: The cluster store (`cluster.store`: the control plane or the shared directory).
- `redis`: A Redis-compatible server (`redis`).

### `cluster.limits.sync_interval`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1s`

How often claims, membership and recovery are attended to (claims a request needs are sent at once). Default 1s (100ms–10s).

## `cluster.store`

**Type:** object

Where certificates, the ACME account, leases and challenge answers are shared. Default: the control plane when `control` is set.

### `cluster.store.barrier_timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `10s`

How long the instance that orders a certificate waits for every live member to hold an HTTP-01 or TLS-ALPN-01 answer before the CA is told to validate. Members that have not confirmed by then cannot answer; validation goes ahead. Default 10s (1s–2m).

### `cluster.store.lease_ttl`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

How long a lease on a certificate name lasts unless its holder renews it (every third of it). Default 60s (10s–10m).

### `cluster.store.path`

**Type:** `string`

The shared directory, for `type: directory`.

### `cluster.store.type`

**Type:** `control` · `directory` · **Default:** `control`

`control` (default) or `directory`.

- `control`: The control plane serves the store to enrolled members over mutual TLS. Leases carry a fencing token the control plane checks on every write.
- `directory`: A directory every instance mounts (NFS, EFS, a shared volume). Best effort: lock files with an expiry that depends on the instances' clocks, and no enforced fencing.
