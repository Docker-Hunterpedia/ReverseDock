TCP routes (SNI routing, passthrough, plain TCP).

## `tcp_routes.<name>.listeners`

**Type:** list of `string`

Listeners (`tcp` or `https`) the route is attached to.

## `tcp_routes.<name>.match`

**Type:** `string` · **Required**

Rule with TCP matchers: ``HostSNI(`db.example.com`)``, ``HostSNI(`*`)``, `ClientIP`, `ALPN`.

## `tcp_routes.<name>.middlewares`

**Type:** list of `string`

Middlewares checked before connecting to the service: `ip_allow`, `ip_deny` and `in_flight` (counted per client IP).

## `tcp_routes.<name>.priority`

**Type:** `integer` · **Default:** `0`

Higher priorities are evaluated first. `0` uses the rule length.

## `tcp_routes.<name>.service`

**Type:** `string` · **Required**

TCP service (a key of `tcp_services`).

## `tcp_routes.<name>.tls`

**Type:** object

TLS handling. Without it the bytes are relayed as they arrive; with it the route matches TLS connections only and terminates TLS unless `passthrough` is set.

### `tcp_routes.<name>.tls.passthrough`

**Type:** `boolean` · **Default:** `false`

Forward the encrypted stream without terminating TLS (routing by SNI only).
