Automatic certificates (ACME). Let's Encrypt with HTTP-01 and TLS-ALPN-01 is used when omitted.

<Status planned="v0.3" />

## `acme.ca`

**Type:** [`CaRef`](/docs/reference/configuration/#caref) · **Default:** `letsencrypt`

Certificate authority: a known name or an `https://` ACME directory URL.

## `acme.challenges`

**Type:** list of `http-01` · `tls-alpn-01` · `dns-01` · **Default:** `["http-01","tls-alpn-01"]`

Challenge types to use, in order of preference.

## `acme.dns_providers`

**Type:** map of names to object, selected by `type`

DNS providers for DNS-01, referenced by routes.

### `type: cloudflare`

Cloudflare DNS with a scoped API token (Zone → DNS → Edit).

#### `acme.dns_providers.<name>.api_token`

**Type:** `string` · **Required**

API token. Reference a secret instead of writing it here: `"${file:/run/secrets/cf_token}"`.

## `acme.eab`

**Type:** object

External account binding, required by some CAs.

### `acme.eab.hmac_key`

**Type:** `string` · **Required**

Base64url HMAC key from the CA. Reference a secret instead of writing it here.

### `acme.eab.key_id`

**Type:** `string` · **Required**

Key identifier from the CA.

## `acme.email`

**Type:** `string`

Contact address for the CA account (optional for Let's Encrypt).

## `acme.profile`

**Type:** `classic` · `tlsserver` · `shortlived`

Certificate profile (Let's Encrypt): `classic` (90 days), `tlsserver` (45 days) or `shortlived` (about 6 days, needed for IP addresses).

- `classic`: 90-day certificates (the default).
- `tlsserver`: 45-day certificates without legacy fields.
- `shortlived`: About 6-day certificates; the only profile that allows IP addresses.

## `acme.staging`

**Type:** `boolean` · **Default:** `false`

Use the CA's staging environment (untrusted certificates, high rate limits).

## `acme.storage`

**Type:** `string`

Where accounts and certificates are stored. Defaults to `$RDOCK_DATA_DIR/acme`.
