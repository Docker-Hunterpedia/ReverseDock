HTTP routes: which requests go to which service, through which middlewares.

## `routes.<name>.enabled`

**Type:** `boolean` · **Default:** `true`

Set to `false` to keep the route defined but inactive.

## `routes.<name>.listeners`

**Type:** list of `string`

Listeners the route is attached to. Defaults to `defaults.listeners`.

## `routes.<name>.match`

**Type:** [`MatchSpec`](/docs/reference/configuration/#matchspec) · **Required**

Requests this route handles: a Traefik v3 rule or a structured match.

## `routes.<name>.middlewares`

**Type:** list of `string`

Middlewares applied in order (`name` or `name@provider`).

## `routes.<name>.mirror`

**Type:** object

Send a copy of requests to another service and ignore its answers.

### `routes.<name>.mirror.percent`

**Type:** `integer` · **Default:** `100`

Share of requests copied, from 1 to 100.

### `routes.<name>.mirror.service`

**Type:** `string` · **Required**

The service that receives the copies (`name` or `name@provider`).

## `routes.<name>.priority`

**Type:** `integer` · **Default:** `0`

Higher priorities are evaluated first. `0` uses the rule length, like Traefik.

## `routes.<name>.service`

**Type:** `string` · **Required**

Service that handles matching requests (`name` or `name@provider`).

## `routes.<name>.timeouts`

**Type:** object · **Default:** `{"connect":null,"read":null,"write":null}`

Upstream timeouts for this route, overriding the service's.

### `routes.<name>.timeouts.connect`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

Establishing a connection.

### `routes.<name>.timeouts.read`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

Waiting for response data.

### `routes.<name>.timeouts.write`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

Sending request data.

## `routes.<name>.tls`

**Type:** [`RouteTls`](/docs/reference/configuration/#routetls)

TLS for this route: `auto`, `off` or detailed settings. Defaults to `defaults.tls`.
