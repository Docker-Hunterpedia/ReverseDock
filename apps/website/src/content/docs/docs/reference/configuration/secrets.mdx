External secret stores that secret fields can reference (`${vault:…}`).

## `secrets.vault`

**Type:** object

A `HashiCorp` Vault or `OpenBao` server whose KV version 2 secrets secret fields may reference as `${vault:<mount>/<path>#<field>}`.

### `secrets.vault.address`

**Type:** [`HttpUrl`](/docs/reference/configuration/#httpurl) · **Required**

The server, e.g. `https://vault.internal:8200`. `https://` only, or `http://` to a loopback address (a dev server or a local agent), unless `insecure_http` is set.

### `secrets.vault.allow_private_targets`

**Type:** `boolean` · **Default:** `true`

Allow a server on a private address (`10.0.0.0/8`, …). On by default: Vault usually runs inside the network.

### `secrets.vault.auth`

**Type:** object, selected by `type` · **Required**

How rdock logs in.

#### `type: undefined`

A token, as a `${file:…}` or `${env:…}` reference (read again on every request, so a token file rotated by an agent is picked up).

#### `secrets.vault.auth.token`

**Type:** `string` · **Required**

#### `type: undefined`

Kubernetes service-account login (`POST /v1/auth/<mount>/login`); the token is renewed by logging in again before its lease runs out.

#### `secrets.vault.auth.kubernetes`

**Type:** object · **Required**

#### `secrets.vault.auth.kubernetes.mount`

**Type:** `string` · **Default:** `kubernetes`

Where the Kubernetes auth method is mounted.

#### `secrets.vault.auth.kubernetes.role`

**Type:** `string` · **Required**

The Vault role to log in as.

#### `secrets.vault.auth.kubernetes.token_file`

**Type:** `string` · **Default:** `/var/run/secrets/kubernetes.io/serviceaccount/token`

The service-account token, read at every login.

### `secrets.vault.ca_file`

**Type:** `string`

CA certificates (PEM) that sign the server's certificate, instead of the system's.

### `secrets.vault.insecure_http`

**Type:** `boolean` · **Default:** `false`

Allow `http://` to a server that is not on a loopback address. **Unsafe**: the token and every secret cross the network unencrypted. Validation warns.

### `secrets.vault.namespace`

**Type:** `string`

A Vault Enterprise or `OpenBao` namespace, sent as `X-Vault-Namespace`.

### `secrets.vault.refresh`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `5m`

How often referenced values are read again.

### `secrets.vault.timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `5s`

Time allowed for one request to the server.
