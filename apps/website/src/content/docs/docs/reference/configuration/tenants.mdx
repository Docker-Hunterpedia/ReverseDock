Tenants of the admin API (H-SEC-07): API tokens and users scoped to a tenant read and write only the API objects under its name prefix, whose routes stay inside its host claims. Without this section, nothing is scoped.

## `tenants.<name>.backend_networks`

**Type:** list of [`IpNetwork`](/docs/reference/configuration/#ipnetwork)

Networks the tenant's backends must be in. Empty: any address except loopback, link-local, unspecified and `localhost`; set: only IP literals inside these networks (DNS names and SRV records are refused, since they can resolve anywhere).

## `tenants.<name>.certificates`

**Type:** list of `string`

Planned: certificates the tenant owns.

:::note[Planned for a later version]
Tenant-owned certificates: accepted by `rdock validate` with a warning, refused by `rdock run` until a later version.
:::

## `tenants.<name>.dashboard`

**Type:** `boolean`

Planned: a dashboard view limited to the tenant.

:::note[Planned for a later version]
A dashboard view limited to a tenant: accepted by `rdock validate` with a warning, refused by `rdock run` until a later version.
:::

## `tenants.<name>.hosts`

**Type:** list of `string`

The host names the tenant's routes may match: `shop.example.com` or `*.shop.example.com` (any name below it, not the name itself). Claims of two tenants may not overlap.

## `tenants.<name>.listeners`

**Type:** list of `string`

Planned: listeners the tenant owns.

:::note[Planned for a later version]
Tenant-owned listeners: accepted by `rdock validate` with a warning, refused by `rdock run` until a later version.
:::

## `tenants.<name>.metrics_label`

**Type:** `boolean`

Planned: a `tenant` label on the core metrics.

:::note[Planned for a later version]
A tenant label on the core metrics: accepted by `rdock validate` with a warning, refused by `rdock run` until a later version.
:::

## `tenants.<name>.prefix`

**Type:** `string`

The start of the names of the tenant's objects in the admin API (routes, services, middlewares). Defaults to `<tenant>-`. No tenant's prefix may start another's.

## `tenants.<name>.shared`

**Type:** object

Objects outside the prefix that the tenant's objects may reference (`name` for the configuration file's, `name@provider` for a provider's).

### `tenants.<name>.shared.caches`

**Type:** list of `string`

Cache stores (`caches`), for `cache` middlewares.

### `tenants.<name>.shared.middlewares`

**Type:** list of `string`

Middlewares.

### `tenants.<name>.shared.services`

**Type:** list of `string`

Services.
