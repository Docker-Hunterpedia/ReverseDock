Tenants of the admin API (H-SEC-07): API tokens and users scoped to a tenant read and write only the API objects under its name prefix, whose routes stay inside its host claims. Without this section, nothing is scoped.

<Status maturity="beta" />

## `tenants.<name>.allow_critical`

**Type:** `boolean`

Let the tenant's routes use `priority_class: critical` with an `admission` middleware it does not own (a shared one). Off: critical traffic on a shared limit is the administrator's to define.

## `tenants.<name>.backend_networks`

**Type:** list of [`IpNetwork`](/docs/reference/configuration/#ipnetwork)

Networks the tenant's backends may connect to. Empty: globally routable unicast addresses only (no loopback, link-local, private, unique-local, shared, multicast, documentation, reserved or cloud metadata address), checked on IP literals at validation and on every address a DNS name or SRV record resolves to, each time it resolves. Set: exactly these networks (a cloud metadata address only when listed on its own), and backends must be IP literals.

## `tenants.<name>.certificates`

**Type:** list of `string`

Planned: certificates the tenant owns.

:::

## `tenants.<name>.hosts`

**Type:** list of `string`

The host names the tenant's routes may match: `shop.example.com` or `*.shop.example.com` (any name below it, not the name itself). Claims of two tenants may not overlap.

## `tenants.<name>.limits`

**Type:** object

Ceilings on what the tenant's objects may hold, so one tenant cannot use up what tenants share (disk, the ACME account's rate limits).

### `tenants.<name>.limits.max_body`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `16MiB`

The largest request body a tenant route accepts, and the most its `hold_body`, `transform` and `validate` middlewares may hold (default 16MiB). A tenant route without `max_body` gets this one, or `security.limits.max_body_bytes` when that is smaller.

### `tenants.<name>.limits.max_middlewares`

**Type:** `integer` · **Default:** `100`

Middlewares the tenant may have (default 100).

### `tenants.<name>.limits.max_routes`

**Type:** `integer` · **Default:** `100`

Routes the tenant may have (default 100).

### `tenants.<name>.limits.max_services`

**Type:** `integer` · **Default:** `100`

Services the tenant may have (default 100).

### `tenants.<name>.limits.max_tls_names`

**Type:** `integer` · **Default:** `20`

Distinct host names the tenant's routes may get automatic certificates for (default 20): each one is an order on the ACME account every tenant shares, and Let's Encrypt limits certificates per registered domain and orders per account.

## `tenants.<name>.prefix`

**Type:** `string`

The start of the names of the tenant's objects in the admin API (routes, services, middlewares). Defaults to `<tenant>-`. No tenant's prefix may start another's.

## `tenants.<name>.shared`

**Type:** object

Objects outside the prefix that the tenant's objects may reference (`name` for the configuration file's, `name@provider` for a provider's).

### `tenants.<name>.shared.caches`

**Type:** list of `string`

Cache stores (`caches`), for `cache` middlewares.

### `tenants.<name>.shared.middlewares`

**Type:** list of `string`

Middlewares.

### `tenants.<name>.shared.services`

**Type:** list of `string`

Services.
