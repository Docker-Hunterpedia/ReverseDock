UDP backend pools.

## `udp_services.<name>.backends`

**Type:** list of object · **Required**

Backend servers (`host:port`; Unix sockets are not supported). `weight` sets each one's share of new sessions; `backup` ones get sessions only when no other is up.

### `udp_services.<name>.backends[].address`

**Type:** [`BackendAddress`](/docs/reference/configuration/#backendaddress) · **Required**

`host:port`, `[ipv6]:port` or `unix:///path.sock`.

### `udp_services.<name>.backends[].backup`

**Type:** `boolean` · **Default:** `false`

Only used when no primary backend is available: the same as `priority: 1`.

### `udp_services.<name>.backends[].for_zones`

**Type:** list of `string`

Zones whose proxies should use this backend under `locality: { mode: prefer }`, instead of its own `zone` (Kubernetes topology hints, `hints.forZones`).

### `udp_services.<name>.backends[].priority`

**Type:** `integer`

Priority tier from 0 (the default, used first) to 7. See the service's `failover`. Not together with `backup`.

### `udp_services.<name>.backends[].weight`

**Type:** `integer` · **Default:** `1`

Relative share of traffic.

### `udp_services.<name>.backends[].zone`

**Type:** `string`

The zone the backend runs in, e.g. `eu-west-1a`, for `locality: { mode: prefer }`.

## `udp_services.<name>.health`

**Type:** object · **Default:** see the fields below

Backend health: passive ejection on ICMP "port unreachable", optional TCP probes.

### `udp_services.<name>.health.passive`

**Type:** object · **Default:** `{"ejection":"30s","enabled":true,"failures":3,"max_ejection_percent":50,"window":"30s"}`

Ejection after ICMP "port unreachable" answers (seen as refused sends or receives on a session's connected socket). On by default.

#### `udp_services.<name>.health.passive.ejection`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30s`

How long an ejected backend gets no new sessions before one session tries it again; doubled for each ejection in a row, up to 5 minutes.

#### `udp_services.<name>.health.passive.enabled`

**Type:** `boolean` · **Default:** `true`

Count refusals and eject backends. `false` only ends the affected session.

#### `udp_services.<name>.health.passive.failures`

**Type:** `integer` · **Default:** `3`

Refusals within `window` that eject a backend.

#### `udp_services.<name>.health.passive.max_ejection_percent`

**Type:** `integer` · **Default:** `50`

Largest share of the pool ejected at once, in percent.

#### `udp_services.<name>.health.passive.window`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30s`

Sliding window for counting refusals.

### `udp_services.<name>.health.tcp_check`

**Type:** object

Periodic TCP connection probes, for backends that also listen on TCP (a DNS server does on port 53). Off by default: a generic UDP probe cannot tell a healthy server from one that drops datagrams.

#### `udp_services.<name>.health.tcp_check.healthy`

**Type:** `integer` · **Default:** `2`

Consecutive successes before a backend is healthy.

#### `udp_services.<name>.health.tcp_check.interval`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `10s`

Time between probes.

#### `udp_services.<name>.health.tcp_check.port`

**Type:** `integer`

TCP port to connect to; the backend's port when omitted.

#### `udp_services.<name>.health.tcp_check.timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `2s`

Probe timeout.

#### `udp_services.<name>.health.tcp_check.unhealthy`

**Type:** `integer` · **Default:** `3`

Consecutive failures before a backend is unhealthy.

### `udp_services.<name>.health.when_all_down`

**Type:** `fail_open` · `fail_closed` · **Default:** `fail_open`

What happens when no backend is healthy.

- `fail_open`: Send to every backend anyway: a broken health check must not cause an outage.
- `fail_closed`: Answer `503`.

## `udp_services.<name>.load_balancer`

**Type:** object · **Default:** `{"policy":"round_robin"}`

How a new session's backend is chosen.

### `udp_services.<name>.load_balancer.policy`

**Type:** `round_robin` · `random` · `least_sessions` · `ip_hash` · **Default:** `round_robin`

Selection policy.

- `round_robin`: Weighted round-robin.
- `random`: Weighted random.
- `least_sessions`: Fewest open sessions relative to the weight.
- `ip_hash`: Consistent hash of the client IP: every session of a client goes to the same backend while it is up.

## `udp_services.<name>.requests`

**Type:** `integer`

Detach a session from its client address after this many datagrams from the client (NGINX `proxy_requests`): the next datagram opens a new session, possibly to another backend, while the detached one still relays its replies until `responses` or `idle` ends it. `1` balances every datagram on its own.

## `udp_services.<name>.responses`

**Type:** `integer`

End a session after this many datagrams from the backend (NGINX `proxy_responses`). `1` suits request-and-answer protocols such as DNS: the socket is released as soon as the answer is relayed. Omitted, a session ends only when idle.

## `udp_services.<name>.timeouts`

**Type:** object · **Default:** `{"idle":"1m"}`

Session timeouts.

### `udp_services.<name>.timeouts.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

A session with no datagram in either direction for this long is closed and its socket released. Default 60 s, Envoy's `udp_proxy` default; Traefik uses 3 s and NGINX 10 minutes (sources in docs/research/v0.8-cache-extensibility.md §5.1, checked 2026-11-11).
