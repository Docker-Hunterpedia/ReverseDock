GeoIP databases for `ClientCountry`, `ClientContinent` and `ClientASN` (H-SEC-04). No database is bundled or downloaded.

## `geoip.asn_database`

**Type:** `string`

An ASN database (`.mmdb`, e.g. GeoLite2-ASN) for `ClientASN`.

## `geoip.database`

**Type:** `string`

A country database (`.mmdb`): gives `ClientCountry` and `ClientContinent`. A file that also carries ASNs (IPinfo Lite) gives `ClientASN` as well.

## `geoip.log`

**Type:** object · **Default:** `{"asn":false,"country":false}`

Opt-in access-log fields; both off by default, since a location tied to an IP address is personal data in many jurisdictions.

### `geoip.log.asn`

**Type:** `boolean` · **Default:** `false`

Log `asn`.

### `geoip.log.country`

**Type:** `boolean` · **Default:** `false`

Log `country` (ISO 3166-1 alpha-2).

## `geoip.max_age`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30d`

The oldest database build accepted, by the build time in its metadata. Default 30 days: the GeoLite End User License Agreement (updated 2026-02-12) requires deleting a version within thirty days of a newer release.

## `geoip.on_stale`

**Type:** `warn` · `refuse` · **Default:** `warn`

What an older database does: `warn` (the default) logs a warning and keeps using it; `refuse` refuses to load it, so the configuration that needs it is refused.

- `warn`: Log a warning and keep using it.
- `refuse`: Refuse to load it.
