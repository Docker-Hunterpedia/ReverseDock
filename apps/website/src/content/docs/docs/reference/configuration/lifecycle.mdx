Start-up and shutdown behaviour.

## `lifecycle.drain_timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `8s`

On shutdown, how long open requests may finish before connections are closed. Keep it below the supervisor's stop timeout (Docker waits 10 s before it kills the process).
