HTTP cache stores, used by `cache` middlewares.

<Status maturity="beta" />

## `type: memory`

Responses in memory, evicted least recently used first beyond `max_size`.

### `caches.<name>.max_size`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `256MiB`

Bytes kept, bodies and headers together.

## `type: disk`

Responses on disk, one file per object, evicted least recently used first beyond `max_size` or `max_objects`. Objects survive restarts.

### `caches.<name>.max_objects`

**Type:** `integer` · **Default:** `1000000`

Objects kept on disk (one file each).

### `caches.<name>.max_size`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `1GiB`

Bytes kept on disk (file sizes).

### `caches.<name>.path`

**Type:** `string`

Directory of the store, absolute; `<data dir>/cache/<name>` when omitted. Created with mode 0700. Anyone who can write it can serve arbitrary content through the cache.
