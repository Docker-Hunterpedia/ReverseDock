Admin API and dashboard.

## `admin.allowed_hosts`

**Type:** list of `string`

Host names the admin listener answers to; other `Host` headers get 421 (DNS-rebinding defence). Default: `localhost`, `127.0.0.1` and `::1` on loopback, the listener's IP otherwise. Required when `listener` is on all interfaces.

## `admin.dashboard`

**Type:** `boolean` · **Default:** `true`

Serve the embedded dashboard on the admin listener.

## `admin.enabled`

**Type:** `boolean` · **Default:** `true`

Serve the admin API.

## `admin.listener`

**Type:** [`ListenAddress`](/docs/reference/configuration/#listenaddress) · **Default:** `127.0.0.1:2080`

Address of the admin API. Loopback by default; any other address needs `tls`.

## `admin.socket`

**Type:** `string`

Unix socket for the local CLI (`rdock reload`, `rdock status`), mode 0600. Default: `$RDOCK_DATA_DIR/admin.sock`.

## `admin.threads`

**Type:** `integer` · **Default:** `2`

Worker threads of the admin runtime, kept apart from the proxy's (1–16).

## `admin.tls`

**Type:** object

TLS for the admin listener. Required when `listener` is not a loopback address.

### `admin.tls.cert_file`

**Type:** `string` · **Required**

PEM certificate chain, leaf first.

### `admin.tls.key_file`

**Type:** `string` · **Required**

PEM private key.
