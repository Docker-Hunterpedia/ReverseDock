Admin API and dashboard.

## `admin.allowed_hosts`

**Type:** list of `string`

Host names the admin listener answers to; other `Host` headers get 421 (DNS-rebinding defence). Default: `localhost`, `127.0.0.1` and `::1` on loopback, the listener's IP otherwise. Required when `listener` is on all interfaces.

## `admin.audit`

**Type:** object · **Default:** `{"forward":null,"max_file_size":"64MiB","retention":"400d"}`

The hash-chained audit log in `$RDOCK_DATA_DIR/audit/`.

### `admin.audit.forward`

**Type:** object

Also send each record to a syslog server.

#### `admin.audit.forward.syslog`

**Type:** `string` · **Required**

Syslog server as `host:port`; records are RFC 5424 messages with the JSON record as the message.

#### `admin.audit.forward.transport`

**Type:** `udp` · `tcp` · **Default:** `udp`

`udp` (default) or `tcp` (octet counting, RFC 6587).

- `udp`: One datagram per record.
- `tcp`: A stream with octet-counted framing.

### `admin.audit.max_file_size`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize) · **Default:** `64MiB`

A file is closed and a new one started at this size (1 MiB–1 GiB).

### `admin.audit.retention`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `400d`

How long rotated files are kept (1d–3650d).

## `admin.dashboard`

**Type:** `boolean` · **Default:** `true`

Serve the embedded dashboard on the admin listener.

## `admin.enabled`

**Type:** `boolean` · **Default:** `true`

Serve the admin API.

## `admin.listener`

**Type:** [`ListenAddress`](/docs/reference/configuration/#listenaddress) · **Default:** `127.0.0.1:2080`

Address of the admin API. Loopback by default; any other address needs `tls`.

## `admin.metrics_unauthenticated_on_loopback`

**Type:** `boolean` · **Default:** `false`

Serve `/metrics` without a token when the listener is a loopback address, as before v0.5, for scrapers on the same machine that cannot send one.

## `admin.mfa`

**Type:** `required_for_admins` · `required` · `optional` · **Default:** `required_for_admins`

Who must use a second factor (TOTP) to log in.

- `required_for_admins`: Admins must enrol before they can do anything else; others may.
- `required`: Every user must enrol.
- `optional`: Nobody must; anyone may.

## `admin.passwords`

**Type:** object · **Default:** see the fields below

Password rules for dashboard users.

### `admin.passwords.argon2`

**Type:** object · **Default:** `{"iterations":2,"memory_kib":19456,"parallelism":1}`

Argon2id cost. Values below the OWASP minimum are refused; existing hashes are upgraded at the next login after a change.

#### `admin.passwords.argon2.iterations`

**Type:** `integer` · **Default:** `2`

Passes over the memory (2–10).

#### `admin.passwords.argon2.memory_kib`

**Type:** `integer` · **Default:** `19456`

Memory per hash in KiB (19456–262144).

#### `admin.passwords.argon2.parallelism`

**Type:** `integer` · **Default:** `1`

Lanes (1–8).

### `admin.passwords.blocklist_file`

**Type:** `string`

A file with one password per line (for example a breached-password list) refused in addition to the bundled list of common passwords. Read once at start, offline.

### `admin.passwords.min_length`

**Type:** `integer` · **Default:** `12`

Shortest password accepted, in characters (8–128). The longest is 128.

## `admin.sessions`

**Type:** object · **Default:** `{"absolute":"8h","idle":"30m"}`

How long a dashboard login lasts.

### `admin.sessions.absolute`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `8h`

A session ends this long after login, however active.

### `admin.sessions.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `30m`

A session without requests for this long ends.

## `admin.socket`

**Type:** `string`

Unix socket for the local CLI (`rdock reload`, `rdock status`), mode 0600. Default: `$RDOCK_DATA_DIR/admin.sock`.

## `admin.threads`

**Type:** `integer` · **Default:** `2`

Worker threads of the admin runtime, kept apart from the proxy's (1–16).

## `admin.tls`

**Type:** object

TLS for the admin listener. Required when `listener` is not a loopback address.

### `admin.tls.cert_file`

**Type:** `string` · **Required**

PEM certificate chain, leaf first.

### `admin.tls.key_file`

**Type:** `string` · **Required**

PEM private key.

## `admin.tokens`

**Type:** object · **Default:** `{"allow_no_expiry":false,"default_expiry_days":90}`

API tokens for scripts and Prometheus.

### `admin.tokens.allow_no_expiry`

**Type:** `boolean` · **Default:** `false`

Allow tokens that never expire. Off by default: a leaked token should stop working.

### `admin.tokens.default_expiry_days`

**Type:** `integer` · **Default:** `90`

Lifetime of a new token when its creator gives none, in days (1–365).
