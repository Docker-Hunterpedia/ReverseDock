Sockets to accept traffic on. When empty, `web` (`:80`) and `websecure` (`:443`, TLS) are used.

## `listeners.<name>.address`

**Type:** [`ListenAddress`](/docs/reference/configuration/#listenaddress) · **Required**

Address to bind, e.g. `:443` or `127.0.0.1:8080`.

## `listeners.<name>.ping`

**Type:** `string`

A path answered `200 OK` for any host before routing, for load-balancer health monitors such as Cloudflare Load Balancing, e.g. `/rdock/ping`.

## `listeners.<name>.protocol`

**Type:** `http` · `https` · `tcp` · `udp`

Protocol. Inferred when omitted: `https` if `tls` is set, otherwise `http`.

- `http`: Plain HTTP/1.1 and h2c.
- `https`: HTTP over TLS (HTTP/1.1 and HTTP/2).
- `tcp`: Raw TCP, optionally with TLS termination or SNI passthrough.
- `udp`: UDP datagrams, relayed per client address (a session) to a UDP service.

## `listeners.<name>.proxy_protocol`

**Type:** object

Accept the PROXY protocol (v1 or v2) from these sources only.

:::note[Planned for a later version]
PROXY protocol on UDP listeners: accepted by `rdock validate` with a warning, refused by `rdock run` until a later version.
:::

### `listeners.<name>.proxy_protocol.optional`

**Type:** `boolean` · **Default:** `false`

Also accept connections from `trusted` sources that send no header. Off by default: a load balancer that stops sending headers would otherwise make every client look like the load balancer itself to IP filters, rate limits and logs.

### `listeners.<name>.proxy_protocol.trusted`

**Type:** list of [`IpNetwork`](/docs/reference/configuration/#ipnetwork) · **Required**

Sources allowed to send a PROXY header, as IP addresses or CIDR networks. Others are rejected when they send one.

## `listeners.<name>.sessions`

**Type:** object

`udp` listeners: how many sessions (client address and port, each with its own upstream socket) may exist at once. Capped by default even when omitted.

### `listeners.<name>.sessions.max`

**Type:** [`SessionLimit`](/docs/reference/configuration/#sessionlimit) · **Default:** `4096`

Sessions of the whole listener. Default 4096: Envoy caps UDP sessions per cluster at 1,024 by default (`max_connections` circuit breaker, checked 2026-11-11 in docs/research/v0.8-cache-extensibility.md §5.1); a listener here stands for a cluster and may serve several clients' DNS bursts, and 4,096 sockets stay far below the container default of 1,048,576 open files. `unlimited` removes the cap.

### `listeners.<name>.sessions.max_per_client`

**Type:** [`SessionLimit`](/docs/reference/configuration/#sessionlimit) · **Default:** `64`

Sessions per client IP address (any source port). Default 64, so one source (or one forged address) can take at most 1/64 of the listener's default budget; a resolver that forwards many parallel queries from one address may need more. `unlimited` removes the cap.

## `listeners.<name>.socket`

**Type:** object

Options of the listening socket and of the connections it accepts (ADR-0031). Unset options keep the kernel's behaviour, except `backlog`, which defaults to 4096.

### `listeners.<name>.socket.backlog`

**Type:** `integer`

TCP: how many connections the kernel holds that have completed their handshake and that ReverseDock has not accepted yet. Default 4096, Linux's `net.core.somaxconn` default since 5.4, which also caps it (before v0.9 it was 128).

### `listeners.<name>.socket.dscp`

**Type:** `integer`

DSCP value (0–63) of the traffic sent on accepted connections (the top six bits of IPv4's TOS byte or IPv6's traffic class).

### `listeners.<name>.socket.fast_open`

**Type:** `integer`

TCP: accept TCP Fast Open with this many pending requests (`TCP_FASTOPEN`). The kernel must allow it for servers (`net.ipv4.tcp_fastopen` bit 2). Linux only; off by default.

### `listeners.<name>.socket.ipv6_only`

**Type:** `boolean`

`IPV6_V6ONLY` for an IPv6 or all-interfaces (`:port`) address: `true` serves IPv6 only, `false` IPv6 and IPv4. Unset: the system's default (`net.ipv6.bindv6only`).

### `listeners.<name>.socket.keepalive`

**Type:** object

TCP keep-alive probes on accepted connections. Unset: off, as the kernel does.

#### `listeners.<name>.socket.keepalive.count`

**Type:** `integer`

Unanswered probes before the connection is dropped (`TCP_KEEPCNT`).

#### `listeners.<name>.socket.keepalive.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

Idle time before the first probe (`TCP_KEEPIDLE`).

#### `listeners.<name>.socket.keepalive.interval`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

Time between probes (`TCP_KEEPINTVL`).

### `listeners.<name>.socket.receive_buffer`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize)

`SO_RCVBUF`: the receive buffer, set before `listen` so the TCP window scale is negotiated with it. Unset: the kernel's automatic sizing.

### `listeners.<name>.socket.reuse_port`

**Type:** `boolean` · **Default:** `false`

TCP: `SO_REUSEPORT`, so several sockets (or processes) can bind the same address and the kernel spreads connections over them. Off by default: with it, another process of the same user can bind the address unnoticed. Refused on `udp` listeners.

### `listeners.<name>.socket.send_buffer`

**Type:** [`ByteSize`](/docs/reference/configuration/#bytesize)

`SO_SNDBUF`: the send buffer. Unset: the kernel's automatic sizing.

### `listeners.<name>.socket.user_timeout`

**Type:** [`Duration`](/docs/reference/configuration/#duration)

TCP: `TCP_USER_TIMEOUT` on accepted connections, how long sent data may stay unacknowledged before the connection is dropped. Linux only.

## `listeners.<name>.starttls`

**Type:** `postgres`

`tcp` listeners: answer a protocol's request to start TLS before reading the TLS ClientHello. Off by default.

- `postgres`: PostgreSQL: answer the 8-byte `SSLRequest` with `S` (and a `GSSENCRequest` with `N`), so clients with the default `sslnegotiation=postgres` reach TCP routes that read SNI.

## `listeners.<name>.timeouts`

**Type:** object · **Default:** `{"idle":"1m","read":"1m","request_header":"10s","write":"1m"}`

Client-side timeouts.

### `listeners.<name>.timeouts.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

How long an idle keep-alive connection is kept open.

### `listeners.<name>.timeouts.read`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

Longest wait for data from the client while a request or upgraded connection is open.

### `listeners.<name>.timeouts.request_header`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `10s`

Time allowed to receive the complete request headers, counted from their first byte (protects against slow-header attacks).

### `listeners.<name>.timeouts.write`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

Longest wait for the client to accept data.

## `listeners.<name>.tls`

**Type:** object

TLS termination settings.

### `listeners.<name>.tls.certificates`

**Type:** list of `string`

Certificates (keys of `certificates`) served by this listener only. When set, the listener presents the one matching the requested name, or the first one, and these certificates are not served by any other listener. Empty, the default: the listener serves the shared certificates (`certificates`, automatic ones, `defaults.certificate`).

### `listeners.<name>.tls.client_auth`

**Type:** object

Client certificates (mTLS). A certificate is always verified against these roots.

#### `listeners.<name>.tls.client_auth.ca_files`

**Type:** list of `string`

PEM files with the CA certificates that sign client certificates.

#### `listeners.<name>.tls.client_auth.cloudflare`

**Type:** `boolean` · **Default:** `false`

Also trust Cloudflare's CA for global Authenticated Origin Pulls.

#### `listeners.<name>.tls.client_auth.mode`

**Type:** `required` · `optional` · **Default:** `required`

`required` refuses handshakes without a valid certificate; `optional` accepts them without one, but verifies a certificate that is sent.

- `required`: Every connection needs a valid certificate.
- `optional`: A certificate is optional; routes can demand one with the `client_cert` middleware.

### `listeners.<name>.tls.max_handshakes`

**Type:** `integer`

`https` listeners: TLS handshakes in progress at once. While the bound is reached, new connections wait in the listen backlog instead of taking CPU from established ones. Unset: no bound (ADR-0031).

### `listeners.<name>.tls.policy`

**Type:** `modern` · `intermediate` · **Default:** `intermediate`

TLS versions and cipher suites.

- `modern`: TLS 1.3 only.
- `intermediate`: TLS 1.2 and 1.3 with forward-secret AEAD ciphers (Mozilla "intermediate").
