Sockets to accept traffic on. When empty, `web` (`:80`) and `websecure` (`:443`, TLS) are used.

## `listeners.<name>.address`

**Type:** [`ListenAddress`](/docs/reference/configuration/#listenaddress) · **Required**

Address to bind, e.g. `:443` or `127.0.0.1:8080`.

## `listeners.<name>.ping`

**Type:** `string`

A path answered `200 OK` for any host before routing, for load-balancer health monitors such as Cloudflare Load Balancing, e.g. `/rdock/ping`.

## `listeners.<name>.protocol`

**Type:** `http` · `https` · `tcp` · `udp`

Protocol. Inferred when omitted: `https` if `tls` is set, otherwise `http`.

- `http`: Plain HTTP/1.1 and h2c.
- `https`: HTTP over TLS (HTTP/1.1 and HTTP/2).
- `tcp`: Raw TCP, optionally with TLS termination or SNI passthrough.
- `udp`: UDP datagrams.

:::note[Planned for v0.6]
TCP and UDP listeners (`tcp`, `udp`): accepted by `rdock validate` with a warning, refused by `rdock run` until v0.6.
:::

## `listeners.<name>.proxy_protocol` <Status planned="v0.6" />

**Type:** object

Accept the PROXY protocol (v1 or v2) from these sources only.

### `listeners.<name>.proxy_protocol.trusted`

**Type:** list of [`IpNetwork`](/docs/reference/configuration/#ipnetwork) · **Required**

Sources allowed to send a PROXY header. Others are rejected.

## `listeners.<name>.timeouts`

**Type:** object · **Default:** `{"idle":"1m","read":"1m","request_header":"10s","write":"1m"}`

Client-side timeouts.

### `listeners.<name>.timeouts.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

How long an idle keep-alive connection is kept open.

### `listeners.<name>.timeouts.read`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

Longest wait for data from the client while a request or upgraded connection is open.

### `listeners.<name>.timeouts.request_header`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `10s`

Time allowed to receive the complete request headers, counted from their first byte (protects against slow-header attacks).

### `listeners.<name>.timeouts.write`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `1m`

Longest wait for the client to accept data.

## `listeners.<name>.tls`

**Type:** object

TLS termination settings.

### `listeners.<name>.tls.client_auth`

**Type:** object

Client certificates (mTLS). A certificate is always verified against these roots.

#### `listeners.<name>.tls.client_auth.ca_files`

**Type:** list of `string`

PEM files with the CA certificates that sign client certificates.

#### `listeners.<name>.tls.client_auth.cloudflare`

**Type:** `boolean` · **Default:** `false`

Also trust Cloudflare's CA for global Authenticated Origin Pulls.

#### `listeners.<name>.tls.client_auth.mode`

**Type:** `required` · `optional` · **Default:** `required`

`required` refuses handshakes without a valid certificate; `optional` accepts them without one, but verifies a certificate that is sent.

- `required`: Every connection needs a valid certificate.
- `optional`: A certificate is optional; routes can demand one with the `client_cert` middleware.

### `listeners.<name>.tls.policy`

**Type:** `modern` · `intermediate` · **Default:** `intermediate`

TLS versions and cipher suites.

- `modern`: TLS 1.3 only.
- `intermediate`: TLS 1.2 and 1.3 with forward-secret AEAD ciphers (Mozilla "intermediate").
