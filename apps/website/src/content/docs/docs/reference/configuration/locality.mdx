The proxy's own zone and whether services prefer backends in it (H-HA-05).

## `locality.mode`

**Type:** `off` · `prefer` · **Default:** `off`

`prefer`: services use only backends of this zone while at least one of them is available, and every backend otherwise (Kubernetes `PreferSameZone`). `off` (the default, as Kubernetes distributes traffic evenly by default) ignores zones. A service's own `locality.mode` overrides this.

- `off`: Every available backend, whatever its zone.
- `prefer`: Only backends in the proxy's zone while at least one of them is available; all otherwise (Kubernetes `PreferSameZone`).

## `locality.zone`

**Type:** `string`

The zone this proxy runs in, e.g. `eu-west-1a`. When omitted, the `RDOCK_ZONE` environment variable gives it; with neither, `prefer` has no effect.
