TCP backend pools.

## `tcp_services.<name>.backends`

**Type:** list of object · **Required**

Backend servers.

### `tcp_services.<name>.backends[].address`

**Type:** [`BackendAddress`](/docs/reference/configuration/#backendaddress) · **Required**

`host:port`, `[ipv6]:port` or `unix:///path.sock`.

### `tcp_services.<name>.backends[].backup`

**Type:** `boolean` · **Default:** `false`

Only used when no primary backend is available: the same as `priority: 1`.

### `tcp_services.<name>.backends[].for_zones`

**Type:** list of `string`

Zones whose proxies should use this backend under `locality: { mode: prefer }`, instead of its own `zone` (Kubernetes topology hints, `hints.forZones`).

### `tcp_services.<name>.backends[].priority`

**Type:** `integer`

Priority tier from 0 (the default, used first) to 7. See the service's `failover`. Not together with `backup`.

### `tcp_services.<name>.backends[].weight`

**Type:** `integer` · **Default:** `1`

Relative share of traffic.

### `tcp_services.<name>.backends[].zone`

**Type:** `string`

The zone the backend runs in, e.g. `eu-west-1a`, for `locality: { mode: prefer }`.

## `tcp_services.<name>.proxy_protocol`

**Type:** `v1` · `v2`

Send a PROXY protocol header to backends.

- `v1`: Text format.
- `v2`: Binary format.

## `tcp_services.<name>.timeouts`

**Type:** object · **Default:** `{"connect":"5s","idle":"10m","termination_delay":"100ms"}`

Connection timeouts.

### `tcp_services.<name>.timeouts.connect`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `5s`

Establishing a connection to a backend.

### `tcp_services.<name>.timeouts.idle`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `10m`

A connection with no data in either direction for this long is closed (NGINX `proxy_timeout`).

### `tcp_services.<name>.timeouts.termination_delay`

**Type:** [`Duration`](/docs/reference/configuration/#duration) · **Default:** `100ms`

Once one side has finished sending, the other side gets this long to finish too before both are closed (Traefik `terminationDelay`).
