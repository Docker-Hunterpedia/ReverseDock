### `tcp_services.<name>.backends[].address`

**Type:** [`BackendAddress`](/docs/reference/configuration/#backendaddress) · **Required**

## `tcp_services.<name>.proxy_protocol`

**Type:** `v1` · `v2`

Send a PROXY protocol header to backends.

- `v1`: Text format.
- `v2`: Binary format.
