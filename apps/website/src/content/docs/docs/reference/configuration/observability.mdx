Logs, metrics and traces.

## `observability.access_log`

**Type:** object · **Default:** `{"format":"json","redact":["authorization","proxy-authorization","cookie","set-cookie"]}`

Access log.

### `observability.access_log.format`

**Type:** `json` · `text` · `off` · **Default:** `json`

Output format.

- `json`: One JSON object per line.
- `text`: Human-readable text.
- `off`: No access log.

### `observability.access_log.redact`

**Type:** list of `string` · **Default:** `["authorization","proxy-authorization","cookie","set-cookie"]`

Header names whose values are replaced by `***`.

Metrics.

### `observability.metrics.prometheus`

**Type:** `boolean` · **Default:** `true`
