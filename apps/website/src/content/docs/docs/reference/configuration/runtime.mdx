How the data plane uses threads.

## `runtime.model`

**Type:** `steal` · `per_core` · **Default:** `steal`

`steal`: one multi-threaded runtime whose workers take work from each other. `per_core` (experimental): one single-threaded runtime per thread, each accepting on its own socket, so a connection is accepted, served and proxied on one thread.

- `steal`: A work-stealing runtime with one worker per CPU.
- `per_core`: One single-threaded runtime per thread, no work stealing.

## `runtime.threads`

**Type:** `integer`

Threads of the `per_core` model (1–1024). Default: the CPUs the process may use, counting its CPU affinity and its cgroup CPU quota (`docker run --cpus`), rounded down.
