The proxy's worker threads; read at start, so a change needs a restart.

## `runtime.max_blocking_threads`

**Type:** `integer`

Most threads for blocking work (file reads, DNS lookups by the system resolver). Unset: 512, tokio's default.

## `runtime.worker_threads`

**Type:** `integer`

Threads that serve connections. Unset: one per CPU the process may use, tokio's default.
