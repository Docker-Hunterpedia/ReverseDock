UDP routes: which `udp` listener's datagrams go to which UDP service.

## `udp_routes.<name>.enabled`

**Type:** `boolean` · **Default:** `true`

Set to `false` to keep the route defined but inactive.

## `udp_routes.<name>.listeners`

**Type:** list of `string`

`udp` listeners the route is attached to (required).

## `udp_routes.<name>.match`

**Type:** `string`

Rule made of ``ClientIP(`…`)`` matchers only (with `&&`, `||`, `!`). Omitted, the route takes every datagram of its listeners; a listener has at most one such route.

## `udp_routes.<name>.middlewares`

**Type:** list of `string`

Middlewares checked before a session is created: `ip_allow` and `ip_deny`. A datagram they refuse is dropped without an answer.

## `udp_routes.<name>.priority`

**Type:** `integer` · **Default:** `0`

Higher priorities are evaluated first. `0` uses the rule length.

## `udp_routes.<name>.service`

**Type:** `string` · **Required**

UDP service (a key of `udp_services`).
