Pinned to **Traefik v3.7** ([Docker label reference](https://doc.traefik.io/traefik/reference/routing-configuration/other-providers/docker/), checked 2026-11-14). Of 250 labels, **135 are translated**: 94 exact and 41 approximate (with the difference stated); 14 need a setting outside labels (manual) and 101 have no equivalent. The Docker provider and `rdock migrate traefik` read labels through the same translator, so this table says what both do.

- **exact**: the same behaviour.
- **approximate**: translated; the difference is stated in the row.
- **manual**: not translated from labels; the row says what to set in rdock.yaml instead. `rdock migrate traefik` reports it as `manual`.
- **none**: no equivalent; the label is reported in the logs, `rdock status` and the migration report, and ignored.

"Proven by" names the fixtures of the [conformance suite](https://github.com/Docker-Hunterpedia/ReverseDock/tree/main/tests/conformance/traefik-labels) that use the label; a test fails when a row has none, when the translator takes a label marked manual or none (or refuses one marked exact or approximate), or when a fixture uses a label that is not in the table. The exact rows are also what the [differential test](https://github.com/Docker-Hunterpedia/ReverseDock/tree/main/tests/conformance/traefik-diff) compares against a running Traefik. The [stability promise](/docs/project/stability/) covers the labels marked exact and approximate.
