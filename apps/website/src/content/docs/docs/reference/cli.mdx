## `rdock run`

```text
Run the proxy

Usage: rdock run [OPTIONS]

Options:
  -c, --config <CONFIG>
          Configuration file [default: /etc/rdock/rdock.yaml]. Without one, rdock runs in zero-config mode: HTTPS on :443 with automatic certificates, :80 redirecting, routes from Docker labels
          
          [env: RDOCK_CONFIG=]

      --data-dir <DATA_DIR>
          Directory for state (configuration history, last-known-good copy, admin token, certificates and the local CA)
          
          [env: RDOCK_DATA_DIR=]
          [default: /var/lib/rdock]

      --no-watch
          Do not reload when the configuration or referenced files change

      --log <LOG>
          Log filter, e.g. `info` or `info,rdock_proxy=debug`
          
          [env: RDOCK_LOG=]
          [default: info]

      --log-format <LOG_FORMAT>
          Format of the application log

          Possible values:
          - auto: JSON unless standard error is a terminal
          - json: JSON lines
          - text: Text
          
          [env: RDOCK_LOG_FORMAT=]
          [default: auto]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version
```
